# 드래곤 성장과 꾸미기

아동 화면의 오늘 학습을 모두 저장하면 하루 달성이 자동 인정된다. 활성 책의 배정된 모든 학습 목표 횟수와 퀴즈 결과(PASS·FAIL)를 확인한다. 학습 목록 끝의 ‘오늘 완료 확인’은 서버 기록을 다시 읽고 누락된 학습으로 이동하는 기능이며 완료를 대신 입력하지 않는다.

## 성장과 보상

첫 달성은 알 선택 자격을 준다. 첫 알 선택 이전 기록을 소급하지 않으며 선택 당일은 0일이다. 이후 달성일마다 성장하고 1일에 부화, 6일에 속성 선택, 18일에 청소년, 30일에 성체가 된다. 쉬는 날과 속성·소품 선택 지연은 기존 누적에 영향을 주지 않는다. 불·번개·얼음 중 한 번 선택한 속성은 바꿀 수 없다.

첫 알 선택 이후 전체 달성일 3일마다 소품 선택 기회 1개가 쌓인다. 전 소품을 모아도 기회는 보관한다. 성체 이후 다음 알 선택을 미루면 소품 진척은 계속 쌓이지만 다음 드래곤의 성장에 소급하지 않는다. 인정된 날짜와 성장은 이후 학습 수정으로 취소되지 않는다.

## 자유 배치

소품 목록에서 미리 보고 선택 기회로 획득한다. 배경은 전체 장면에 적용하며 둥지·장식 2개를 드래그 또는 방향키·방향 버튼으로 이동한다. 위치는 장면의 비율 좌표(15~85)로 제한하여 다른 화면에서도 소품이 잘리지 않게 한다. ‘기본 위치’는 선택한 자리만 되돌린다. ‘꾸미기 저장’ 전의 배치는 임시이며 변경 취소·닫기·다른 드래곤 선택으로 버릴 수 있다.

보유 소품은 아동 공용, 배치는 드래곤별이다. 다른 화면에서 배치가 바뀌면 버전 충돌을 안내하며 최신 상태를 불러온 뒤 다시 편집한다. 배치·소품·속성·알의 동일 요청 재시도는 중복 지급하지 않는다.

## DB 적용과 카탈로그 추가

앱 배포 전에 `supabase/migrations/20261103120000_dragon_world.sql`을 적용한다. 기존 학습 테이블의 마이그레이션이 선행되어야 한다. 새 테이블은 RLS와 읽기 권한만 제공한다. 쓰기는 소유자를 확인하는 `dragon_world` RPC와 학습 저장 트리거를 통해 수행한다. 서비스 키는 클라이언트에서 사용하지 않는다.

- `dragon_days`: 아동·날짜별 한 번의 달성 원장.
- `dragon_progress`: 첫 알 선택일과 전체 소품 보상 달성일.
- `dragons`: 개별 알·성장·속성·좌표·꾸미기 버전.
- `dragon_owned_items`: 아동별 보상 소품 획득 내역. 획득 수를 이미 사용한 기회 수로 계산한다.
- `dragon_items`: 기본/보상 소품 카탈로그. stable ID를 유지하고 새로운 ID의 행을 추가한다. 기존 행 삭제·free 속성 변경은 별도 데이터 전환 없이 하지 않는다.

`dragon_items`의 `name`, `kind`(background/nest/prop), `art`, `free`, `sort_order`로 목록을 구성한다. 추가 행은 자동으로 선택 목록에 나타난다. 새 원화를 쓰려면 `app/dragon-scene.tsx`와 해당 CSS/정적 자산을 함께 추가한다. 미등록 장식 art는 별 모양, 배경·둥지는 기본 표현으로 표시한다. 자유 배치·성장 로직은 바꿀 필요 없다.

`security definer`는 보상 원장의 직접 변조를 막기 위해 사용한다. 내부 helper/trigger 함수의 외부 실행을 취소하고 공개 RPC에서 `auth.uid()` 소유권과 입력을 확인하며 고정된 빈 search_path를 사용한다. 아동 행 잠금으로 보상·선택 쓰기를 직렬화한다. 달성일은 서버의 한국 날짜이며 과거 날짜 입력을 받지 않는다.

학습 저장 트리거는 횟수와 퀴즈 저장 트랜잭션 안에서 달성을 인정한다. 첫 앱 진입·학습 갱신·완료 확인·온라인 복귀 시 RPC를 다시 조회한다. DB 적용 실패는 학습 저장에도 영향을 줄 수 있으므로 마이그레이션 검증 후 앱을 배포한다.

## 검증

`npm run test:server -- tests/server/dragon-db.test.ts`는 모든 실제 마이그레이션을 로컬 PGlite PostgreSQL 엔진에 적용해 트리거·RPC·RLS를 실행한다. auth.uid()·역할은 테스트 대역이며 pgcrypto 설치만 제외한다(내장 gen_random_uuid 사용). 외부 Supabase에 연결하지 않는다. 단일 연결 엔진이므로 실제 다중 연결의 잠금 경쟁 검증을 대체하지 않는다.

`npm run test:browser:client -- dragon-world.spec.mjs`는 로컬 HTTP 대역으로 320·390·1280px 화면의 미리보기·획득·드래그·저장·재조회와 완료 확인을 검증한다. 원화·DOM·포인터는 실제 브라우저를 사용하고 보상 DB 규칙은 위 DB 테스트에서 따로 검증한다.
