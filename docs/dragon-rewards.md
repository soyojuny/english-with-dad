# 드래곤 성장과 꾸미기

아동 화면의 오늘 학습을 모두 저장하면 하루 달성이 자동 인정된다. 활성 책의 배정된 모든 학습 목표 횟수와 퀴즈 결과(PASS·FAIL)를 확인한다. 학습 목록 끝의 ‘오늘 완료 확인’은 서버 기록을 다시 읽고 누락된 학습으로 이동하는 기능이며 완료를 대신 입력하지 않는다.

## 드래곤 화면

아동 화면의 ‘읽기·DVD 기록’ 옆 ‘드래곤’ 버튼으로 전용 화면을 연다. 큰 16:9 장면과 꾸미기 도구를 사용하며 1000px 이상에서는 옆에, 작은 화면에서는 아래에 도구를 표시한다. ‘오늘의 학습으로’ 돌아갈 수 있고 기록 팝업도 기존처럼 사용할 수 있다. 다른 아동 프로필을 선택하면 학습 화면에서 시작하며 드래곤 상태는 아동별로 분리한다.

알 3종·아기 4모습(무속성·불·번개·얼음)·불 성체는 새 원화를 사용하고, 나머지 성장·속성 모습은 기존 원화를 유지한다. 무속성·불·번개·얼음 아기는 장면의 아무 곳에서나 드래그해 나타나는 스틱으로 이동한다. 손을 떼면 서서 숨을 쉬고 눈을 깜빡인다. 무속성·불 아기는 5초 동안 조작하지 않으면 각자의 5자세 시트로 앉고 터치하면 일어선다. 번개·얼음 아기는 서서 쉰다. 꾸미기 중에는 이동하지 않는다. 날기 획득과 조작은 아래 무속성·불·번개 아기 날기 규칙을 따른다.

## 성장과 보상

첫 달성은 알 선택 자격을 준다. 첫 알 선택 이전 기록을 소급하지 않으며 선택 당일은 0일이다. 이후 달성일마다 성장하고 1일에 부화, 6일에 속성 선택, 18일에 청소년, 30일에 성체가 된다. 쉬는 날과 속성·소품 선택 지연은 기존 누적에 영향을 주지 않는다. 불·번개·얼음 중 한 번 선택한 속성은 바꿀 수 없다.

첫 알 선택 이후 전체 달성일 3일마다 소품 선택 기회 1개가 쌓인다. 전 소품을 모아도 기회는 보관한다. 성체 이후 다음 알 선택을 미루면 소품 진척은 계속 쌓이지만 다음 드래곤의 성장에 소급하지 않는다. 인정된 날짜와 성장은 이후 학습 수정으로 취소되지 않는다.

## 자유 배치

현재는 제공된 배경 4종과 석비·용암 수정만 무료로 고른다. 배경은 썸네일로 선택해 전체 장면에 적용하고 장식 2개를 드래그 또는 방향키·방향 버튼으로 이동한다. 둥지와 예전 이모지 장식은 제공하지 않는다. 기회는 기능이나 향후 새 소품을 위해 계속 보관하며 현재 기본 소품 선택에는 차감하지 않는다. 위치는 장면의 비율 좌표(15~85)로 제한하여 다른 화면에서도 소품이 잘리지 않게 한다. ‘기본 위치’는 선택한 자리만 되돌린다. ‘꾸미기 저장’ 전의 배치는 임시이며 변경 취소·오늘의 학습으로 이동·다른 드래곤 선택으로 버릴 수 있다.

보유 소품은 아동 공용, 배치는 드래곤별이다. 다른 화면에서 배치가 바뀌면 버전 충돌을 안내하며 최신 상태를 불러온 뒤 다시 편집한다. 배치·소품·속성·알의 동일 요청 재시도는 중복 지급하지 않는다.

## DB 적용과 카탈로그 추가

앱 배포 전에 `supabase/migrations/20261103120000_dragon_world.sql`과 `20261104120000_dragon_habitat_items.sql`, `20261104130000_dragon_decor_without_nest.sql`을 순서대로 적용한다. 기존 학습 테이블의 마이그레이션이 선행되어야 한다. 새 테이블은 RLS와 읽기 권한만 제공한다. 쓰기는 소유자를 확인하는 `dragon_world` RPC와 학습 저장 트리거를 통해 수행한다. 서비스 키는 클라이언트에서 사용하지 않는다.

- `dragon_days`: 아동·날짜별 한 번의 달성 원장.
- `dragon_progress`: 첫 알 선택일과 전체 소품 보상 달성일.
- `dragons`: 개별 알·성장·속성·좌표·꾸미기 버전.
- `dragon_owned_items`: 아동별 보상 소품 획득 내역. 획득 수를 이미 사용한 기회 수로 계산한다.
- `dragon_items`: 기본/보상 소품 카탈로그. stable ID를 유지하고 새로운 ID의 행을 추가한다. 기존 행 삭제·free 속성 변경은 별도 데이터 전환 없이 하지 않는다.

신규 카탈로그 migration은 용암 계곡·넓은 바위 터·중앙 화산·용암 폭포와 고대 드래곤 석비·용암 수정을 기본 무료로 추가한다. 새 알의 기본 배치는 용암 계곡·석비·수정이다. 화면과 RPC가 제공하는 목록 및 저장 가능한 ID는 이 6종으로 제한한다. 배치 계약은 background/left/right 세 자리이며 nest 입력은 거절한다. 기존 저장 행을 일괄 초기화하거나 삭제하지 않고 조회에서는 지원하는 원화만 투영하며, 명시적인 꾸미기 저장 때 현재 세 자리를 기록한다.

`dragon_items`에는 `name`, `kind`, `art` 식별자와 무료 여부가 들어 있다. 이미지 바이트·base64·원본 PNG는 DB에 저장하지 않는다. 원본은 `assets/dragons/source/`, 배포 파일은 `public/assets/dragons/`다. `npm run build`가 prebuild에서 `npm run assets:dragons`를 실행해 정식 원본으로 WebP 34개를 재생성한다. 계획 폴더나 로컬 다운로드 경로에 의존하지 않는다.

새 원화를 추가하려면 `lib/dragon-art.ts`와 빌드 목록, 카탈로그 허용 목록(앱 `availableDragonItems`와 RPC)을 함께 갱신한다. 미지원 소품은 목록·장면·저장 모두 허용하지 않는다. 원본·출력 대응과 후속 동작 프레임 상태는 `assets/dragons/README.md`를 따른다.

`security definer`는 보상 원장의 직접 변조를 막기 위해 사용한다. 내부 helper/trigger 함수의 외부 실행을 취소하고 공개 RPC에서 `auth.uid()` 소유권과 입력을 확인하며 고정된 빈 search_path를 사용한다. 아동 행 잠금으로 보상·선택 쓰기를 직렬화한다. 달성일은 서버의 한국 날짜이며 과거 날짜 입력을 받지 않는다.

학습 저장 트리거는 횟수와 퀴즈 저장 트랜잭션 안에서 달성을 인정한다. 첫 앱 진입·학습 갱신·완료 확인·온라인 복귀 시 RPC를 다시 조회한다. DB 적용 실패는 학습 저장에도 영향을 줄 수 있으므로 마이그레이션 검증 후 앱을 배포한다.

## 검증

`npm run test:server -- tests/server/dragon-db.test.ts`는 모든 실제 마이그레이션을 로컬 PGlite PostgreSQL 엔진에 적용해 트리거·RPC·RLS를 실행한다. auth.uid()·역할은 테스트 대역이며 pgcrypto 설치만 제외한다(내장 gen_random_uuid 사용). 외부 Supabase에 연결하지 않는다. 단일 연결 엔진이므로 실제 다중 연결의 잠금 경쟁 검증을 대체하지 않는다.

`npm run test:browser:client -- dragon-world.spec.mjs`는 로컬 HTTP 대역으로 320·390·800·1280px 화면의 배경 선택·무료 장식·드래그·저장·재조회와 완료 확인을 검증한다. 원화·DOM·포인터는 실제 브라우저를 사용하고 보상 DB 규칙은 위 DB 테스트에서 따로 검증한다.

무속성·불 아기의 이동 중 걷기는 각 속성에 승인된 B→D→E 세 자세를 5fps로 반복한다. 번개 아기도 제공 원본에서 추출한 세 자세를 동일한 시트 규격과 5fps로 반복한다. 정지 자세는 반복에서 제외하며, 교차 페이드 없이 무손실 걷기 시트의 프레임을 교체한다. 움직임 줄이기에서는 정지 원화를 사용한다. 얼음도 승인된 B→D→E 세 자세를 같은 규격·속도로 반복하고 멈추면 서서 쉰다. 원본 출처와 정렬 기준은 `assets/dragons/README.md`에 기록한다.

아동 화면의 무속성 아기 앉기는 승인된 서기→2rus-2→새 A→새 B→4ier-1 순서로 300ms씩 표시한다. 5초 대기 후 하강을 시작해 1.2초 뒤 최종 자세에서 쉬며, 터치하면 현재 자세부터 역순으로 일어선다. 하강 도중 터치해도 마지막 자세로 뛰지 않는다. 크기·접지는 기존 서기와 맞춘 5칸 무손실 시트를 사용한다. 움직임 줄이기에서는 중간 자세를 생략한다. 승인된 B→D→E 걷기와 스틱 이동 규칙은 유지한다.

불 아기의 앉기도 같은 대기·전환·역순 일어서기 규칙을 사용한다. 첫 칸은 기존 불 서기 원화를 그대로 유지하고 나머지 네 자세는 제공 원본의 RGB를 보존한 채 알파로 체크 배경만 분리해 앞발 접지를 맞췄다. 생성형 배경 제거로 색이 바뀌었던 이전 시트는 교체했다. 정식 PNG와 출처·RGB 검증·배치 기록은 `assets/dragons/source/baby/fire-sit-sequence.*`이며 배포 WebP는 5120×1024 무손실이다.

번개 아기의 앉기도 무속성과 같은 5초 대기·300ms 5자세 전환·현재 자세부터 역순 일어서기 규칙을 사용한다. 첫 칸은 기존 번개 서기 원화를 유지하고, 나머지 네 칸은 제공 원본의 2–5번을 생성형 투명 분리한 승인 시안이다. 원본 세부와 일부 다를 수 있으며 크기·앞발 접지를 정렬했다. 정식 PNG와 출처·배치 기록은 `assets/dragons/source/baby/thunder-sit-sequence.*`, 배포 WebP는 5120×1024 무손실이다. 기존 번개 걷기와 정지 호흡·깜빡임을 유지하며 움직임 줄이기에서는 중간 자세를 생략한다.

얼음 아기의 앉기는 승인된 네 자세를 사용한다. 첫 칸은 기존 얼음 서기이며 이후 A-3→A-4→A-5를 300ms씩 표시한다. 5초 대기 후 900ms에 최종 자세에 도달하고, 터치하면 현재 자세부터 역순으로 일어선다. 알·청소년·성체와 꾸미기 중에는 적용하지 않는다. 움직임 줄이기에서는 중간 자세를 생략한다. 정식 원본과 배치는 `assets/dragons/source/baby/ice-sit-sequence.*`에 보관하며 PWA v20에 4096×1024 무손실 WebP를 캐시한다.

## 무속성·불·번개 아기 날기

3일마다 누적되는 보상 선택 기회로 선택한 드래곤에게 날기를 가르칠 수 있다. 최초 획득은 무속성·불·번개 아기(1~17일)만 허용하고 기회 1개를 사용한다. 중복 요청은 추가 차감하지 않는다. 소품은 기존과 같이 아동 공용이고 기능은 드래곤별이며, 성장하거나 속성을 선택해도 획득 기록은 유지한다. 날기 원화의 사용 범위는 무속성·불·번개 아기이므로 다른 형태에서는 날기 버튼을 표시하지 않는다. 무속성일 때 배운 날기는 불·번개 속성을 선택해도 다시 획득하지 않고 사용한다.

획득 후 장면 아래 ‘날기’를 누르면 날개짓하며 올라가고, 스틱을 좌우로 드래그하면 해당 방향으로 비행한다. 손을 떼면 같은 높이에서 공중에 머문다. 같은 버튼을 다시 누르면 이륙을 역순으로 재생하며 지상으로 돌아간다. 날개가 장면 밖으로 나가지 않도록 이륙 시 가로 위치를 25~74% 안으로 옮기고 비행 중에도 유지한다. 이착륙 도중에는 이동과 버튼 재입력을 막으며 공중에서는 자동으로 앉지 않는다. 위치와 비행 여부는 일시 상태이고 새로고침·드래곤/속성/성장 변경·꾸미기 진입 때 지상으로 초기화한다. 움직임 줄이기에서는 중간 이착륙과 반복 날개짓을 생략하지만 버튼과 좌우 이동은 유지한다.

`20261108120000_dragon_flight.sql`은 기존 `dragons`에 비어 있는 `skills` 배열을 추가하고 `dragon_world` RPC에 `skill` 동작을 추가한다. 기존 아동 소유권 확인·행 잠금·RLS·직접 변경 금지는 유지한다. 남은 보상 기회는 전체 달성일/3에서 보상 소품 수와 드래곤별 획득 기능 수를 함께 차감한다. 최초 도입 당시 기능 입력은 `fly`만 허용했다. 앱 적용 전 해당 마이그레이션을 적용해야 한다.

정식 시트는 새 캡처 13~42번(25·26번은 승인된 기존 14·15번 교체), 기존 이동 36~47번, 공중 대기 58~66번이다. 각 시트는 640×640 공통 칸을 6열로 배치하고 12fps로 재생한다. 착륙은 이륙과 동일한 시트를 역순으로 사용한다. 원본 영상 FPS 메타데이터는 없어 12fps를 기본으로 정했다. 검정 배경은 바깥과 연결된 어두운 픽셀의 알파만 제거하고 원본 RGB·형태는 유지했다. 원본 출처와 해시는 `assets/dragons/source/baby/flight.json`에 기록하며 빌드는 검토 폴더 대신 정식 PNG만 읽는다. WebP 3개를 PWA v21에 포함한다.

불 아기 확장에는 `20261108130000_fire_dragon_flight.sql`을 추가 적용한다. 획득 허용 속성만 무속성·불로 넓히고 기존 권한·행 잠금·차감·중복 요청 처리는 유지한다. 불 시트는 승인한 미리보기의 이륙·오른쪽 비행 각 8프레임을 4열×2행으로 사용하며 8fps로 재생한다. 공중 대기는 이동 시트의 날갯짓, 착륙은 이륙 역순이다. 불 전용 PNG 출처와 SHA-256은 `assets/dragons/source/baby/fire-flight.json`에 기록하고, WebP 두 개를 PWA v22에 추가한다.

## 불 아기 분신 관찰 놀이 · 2026-11-14

불 아기(1~17일)는 기존 기능과 같은 선택 기회 1개로 `clone`을 배운다. `20261114120000_fire_clone.sql`은 기능 배열 제약과 `dragon_world`의 허용 기능을 확장한다. 기존 소유권·아동 행 잠금·RLS·직접 수정 금지와 중복 요청의 무차감을 유지한다. 습득한 기능은 성장 후에도 기록에 남지만 아기일 때만 사용할 수 있다. 운영에서 획득하려면 배포 전에 migration을 적용해야 한다. 분신 놀이는 지상에서 시작하며 비행·공격 중에는 시작하지 못한다. 놀이 중에는 원래 배경·장식을 유지하고 기존 드래곤 대신 같은 장면 위에 분신을 표시한다. 기존 이동·비행·공격은 멈춘다. 종료·드래곤 선택·성장·속성 변경·꾸미기 전환은 놀이를 종료한다. 화면이 숨겨지면 재생을 멈추고 복귀 시 같은 단서를 다시 보여 준다.

세 마리를 같은 주기로 재생하고 원래 16:9 장면 곳곳에 무작위로 배치한다. 카드·칸·번호 표시는 없고 드래곤 자체를 터치한다. 각 드래곤의 영역은 장면 너비의 24%인 정사각형이며 장면 밖 잘림과 서로의 터치 영역 겹침을 피한다. 배경·장식 위에 표시해 선택을 가리지 않는다. 난이도 선택 없이 매 놀이마다 앉았다 일어서기 또는 두 번 깜빡임 후 앉기를 무작위로 정한다. 단서 행동을 한 번(5.2초) 보여 준 뒤 0.6초 동안 원래 드래곤이 불꽃 속에서 사라지고, 흩어진 위치에 0.6초 동안 세 마리가 나타난다. 등장 완료 전에는 선택하지 못한다. 오답은 흐리게 표시하고 다시 선택하지 못하게 한다. 단서 다시 보기는 같은 문제·분신 위치·제거한 분신을 유지한다. 새로 놀기는 난이도·진짜·배치를 다시 무작위로 정한다. 단서 다시 보기도 같은 단서를 한 번 재생한 뒤 소멸·생성을 다시 보여 준다. 정답을 찾으면 1.2초 동안 진짜가 반짝이고 나머지 분신이 사라진 뒤 놀이를 자동 종료해 원래 대기 모습으로 돌아간다. 전환·정답 효과도 일시정지와 화면 숨김을 따른다. 시간 제한·결과 저장·추가 보상은 없다. 움직임 줄이기에서는 중간 앉기·걷기 자세를 생략하되 깜빡임 횟수는 유지한다.
