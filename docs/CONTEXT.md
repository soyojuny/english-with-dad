# English With Dad

This context describes the parent-managed child reading assignment domain for English With Dad.

## Language

**Activity Category**:
A parent-facing grouping that determines how an assigned material appears in activity management reports.
_Avoid_: Assignment type, task type

**Task**:
A concrete child action within an assignment, such as opening the reading audio and marking one completion.
_Avoid_: Activity, category

**English Picture Book Reading**:
An activity category for assigning an English book as one reading-audio completion. It uses the same reading task as other book assignments, but reports under the English picture book column.
_Avoid_: English picture book task, separate material type
