# 02 — 화면 위 모달 표시

## Goal

현재 보고 있는 화면 위에 팝업을 표시하고 기존 입력·저장 흐름을 유지한다.

## Work

- 대상 dialog를 `showModal()`로 열고 닫기·취소·Escape·저장 성공을 React 열림 상태와 연결한다.
- 수명주기와 UI는 필요하면 전용 컴포넌트로 분리하며, 기존 저장 핸들러를 연결한다.
- `.quick-log-dialog`에 화면 기준 배치, 여백, 최대 높이와 내부 스크롤을 적용한다.
- 접근 가능한 이름, 초기 입력 포커스, 모달 내부 Tab 이동과 닫기 후 포커스 복원을 확인한다.
- 열기·닫기 후 페이지 위치를 유지하고, 필요한 배경 스크롤 제어는 해제 시 원래 상태로 복원한다.
- 저장 실패 시 입력값 유지와 보이는 오류 안내를 확인한다. 기존 toast가 모달 뒤에 가려질 경우만 최소 수정한다.
- QR 팝업 스타일과 저장 payload는 변경하지 않는다.

## Verify

- Task 01 위치 회귀 테스트가 통과한다.
- 닫기·취소·Escape·저장 성공 후 재열기가 동작하고, unmount와 effect 재실행에도 오류가 없다.
- 기존 아동 수기 기록 정상·빈 제목·실패 테스트를 실행한다.
- `npm run check:contracts`, `npm run check:pwa`, `npm run typecheck` 통과.

## Result

완료. 전용 컴포넌트의 native modal·포커스·스크롤 복원과 인라인 오류 안내를 구현했다. 위치·수명주기·저장 회귀와 실제 StrictMode effect 재실행 검증이 통과했다. 상세 결과는 [review.md](../review.md)에 기록했다.
