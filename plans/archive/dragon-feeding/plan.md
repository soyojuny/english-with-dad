# 아동 먹이 주기

사용자가 승인한 ‘조금씩 베어 먹기’를 아동 화면에 연결한다. 불·번개 아기만 먹기 동작을 사용한다. 먹이 6종은 기존 3일 달성 보상 선택 기회와 공유하며, 아동 공용으로 한 번 해금하면 사용 횟수 제한이나 추가 차감이 없다. 기존 기능·무료 장식·성장 규칙은 유지한다.

1. 기존 카탈로그/보유 원장과 claim RPC에 먹이를 추가한다. → 실제 마이그레이션 DB 테스트로 기회 경계·재시도·다른 아동/가족 격리를 검증한다.
2. 해금·먹이 선택 UI와 9개 자세·3회 씹기·뼈·남은 송이를 연결한다. → 동작 상호 배제·앉기 해제·선택/성장/꾸미기/백그라운드 취소·재사용·움직임 줄이기 테스트.
3. 정식 PNG를 추가 축소 없이 무손실 WebP로 빌드하고 PWA 캐시를 갱신한다. → 알파·보이는 RGB 일치, 모바일/데스크톱 실제 아동 화면, npm run verify.

먹이의 현재 선택과 재생 위치·남은 음식은 영구 저장하지 않는다. 새 먹기·이동·화면 전환은 이전 장면을 정리한다. 2026-11-19 사용자가 배경 정리 이미지를 확정하고 불필요한 자료 정리·커밋·푸시·운영 DB 반영을 승인했다. 공개 사이트 배포는 별도다. 추가 인터뷰가 필요한 시각·보상 규칙은 앞선 사용자 승인으로 확정되어 있다.
