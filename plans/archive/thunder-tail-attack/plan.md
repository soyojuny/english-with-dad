# 번개 아기 꼬리 공격

## Goal

승인된 43프레임을 정식 기능으로 제공하고 기존 3일 보상 선택 기회 1개로 드래곤별 획득을 저장한다. 사용자는 추가 확인 없이 끝까지 진행하도록 요청했다.

## Decisions

- 번개 아기(1~17일)에게만 `tail-attack`을 최초 획득·사용하도록 허용한다. 속성 선택은 기존 6일 규칙을 유지한다.
- 날기와 보상 기회를 공유한다. 두 기능을 함께 소유할 수 있고 재시도에는 추가 차감하지 않는다.
- 지상의 버튼으로 43프레임을 18fps로 한 번 재생한다. 공격 중 이동·날기·재시작을 막고 서기로 복귀한다. 앉아 있으면 일어서기를 마친 뒤 공격한다.
- 다른 드래곤·성장·꾸미기·백그라운드 전환에는 공격을 취소한다. 움직임 줄이기는 한 공격 자세만 짧게 표시한다.
- 승인된 601×361px 셀을 유지하고 배포 WebP는 무손실로 생성한다. 기존 서기 크기·접지와 정렬한다.
- 기존 소유권 검증, 아동 행 잠금, RLS와 직접 변경 금지를 유지한다.

## Out of Scope

다른 속성·성장 단계의 공격, 전투/데미지, 자동 반복, 커밋·웹 배포.

## Tasks

1. DB와 보상 획득 → 검증: 실제 마이그레이션을 실행하는 DB 테스트와 권한·재시도·기회 경계.
2. 동작·UI·에셋·캐시 → 검증: hook/component 테스트와 모바일/데스크톱 브라우저.
3. 전체 검증 및 연결 DB 적용 → 검증: `npm run verify`, DB 마이그레이션 확인과 advisors.

## Required Verification

정상·경계·잘못된 입력의 획득, 두 기능 공존, 43프레임 종료, 앉기/날기/이동 충돌 방지, 감소 동작, 초기화, PWA 에셋 캐시.
