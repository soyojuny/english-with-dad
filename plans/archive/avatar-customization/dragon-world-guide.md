# 작은 드래곤의 숲 · 시안 검토

[체험 화면](dragon-world.html)은 앱 구현에 앞서 외형과 흐름을 정하기 위한 독립 HTML이다. 브라우저에서 파일을 열면 동작하며 설치나 로그인은 필요 없다. `dragon-world.html`, CSS, JS, `dragon-assets/`를 같은 위치에 유지한다.

**시작 순서 차이:** 현재 시안은 첫 학습 완료 전에도 알을 고를 수 있다. 이후 확정된 규칙은 첫 완료일에 알 선택권을 얻고 그날을 0일로 세며, 알 선택 이후의 다음 달성일부터 성장·소품 보상을 누적한다. 아래 체험 순서는 시안의 현재 동작을 설명한다.

로컬 서버로 여는 경우 저장소 루트에서:

```bash
python3 -m http.server 4177 --bind 127.0.0.1 --directory plans/archive/avatar-customization
```

브라우저 주소: <http://localhost:4177/dragon-world.html>

정적 화면 미리보기: [데스크톱](dragon-assets/preview-desktop.png) · [모바일](dragon-assets/preview-mobile.png).

## 5분 체험 순서

1. **알 선택 → 하루 목표 달성해 보기**: 알 무늬와 진주빛 아기를 본다. 버튼 한 번은 다음 학습일 전체 완료를 가정한다.
2. **시간 여행 → 6일 → 속성 선택**: 불·번개·얼음 중 고르고 확정한다. 속성은 이 친구에게 고정되고 소품 선택 기회 2개는 별도로 남는다.
3. **공간 꾸미기**: 자리를 고르고 잠긴 소품을 눌러 미리 놓아본다. 선택 기회가 있으면 받아서 배치한다. 선택을 미뤄도 기회가 유지된다.
4. **성장 도감**: 세 속성의 1·6·18·30일 외형을 비교한다. 도감의 속성 비교는 키우는 친구의 속성을 바꾸지 않는다.
5. **시간 여행 → 30일 → 다음 알 만나기**: 새 알을 선택한 뒤 하루 달성을 체험한다. 새 드래곤의 1일과 전체 보상 누적 31일을 구분해서 본다. 나의 드래곤에서 기존 성체를 다시 꾸며본다.
6. **오늘의 학습**: 작은 드래곤으로 진입하는 동선, 남은 읽기 횟수, 퀴즈 결과를 확인한다. 읽기 2회와 퀴즈 결과를 입력하면 확인 버튼 없이 자동 달성한다. FAIL도 인정한다. 완료 확인을 반복하거나 읽기 기록을 줄여도 이미 인정된 성장은 유지한다.

시간 여행은 해당 장면의 새 체험을 연다. 이전 소품·드래곤·누적은 초기화되며 화면에도 이를 안내한다. 18·30일 장면은 도감에서 마지막으로 본 속성을 사용한다. 새로고침 시에도 초기화된다.

## 화면을 보며 정할 것

| 검토 항목 | 시안의 추천안 | 확인할 질문 |
| --- | --- | --- |
| 알 | 무늬가 다른 알 3개, 같은 종으로 부화, 속성과 무관 | 2026-10-26 확정. |
| 부화 전 공개 | 부화할 무속성 아기를 알 선택 화면에서 미리 보여준다 | 2026-10-27 확정. 원화의 구체적인 표현은 계속 검토한다. |
| 외형 | 다정한 아기 → 뿔·날개가 큰 성체 | 성체의 강인함과 아기의 귀여움이 원하는 수준인가? |
| 성장 단계 | 1일 부화·6일 속성 선택 가능·18일 청소년·30일 성체 | 단계와 시점은 2026-10-26 확정. 구체적인 외형은 계속 검토한다. |
| 꾸미기 | 배경 1 · 둥지 1 · 주변 장식 2 | 드래곤이 잘 보이고 선택이 가벼운가? |
| 소품 | 기본 3종 + 비우기, 보상 8종 | 소품의 종류·수량·보상 속도가 적절한가? |
| 수집 | 성체 완성 → 다음 알 선택, 옛 친구 재방문 | 다음 알을 고르고 옛 친구에게 돌아가는 흐름이 자연스러운가? |

보상 소품: 노을 언덕, 달빛 숲, 수정 둥지, 고대의 둥지, 소원 수정, 별빛 등불, 용기의 깃발, 동화 버섯. 8개는 검토용 구성이다. 모두 모으면 수집 완료를 표시하고 미사용 선택 기회는 보관하는 안이다.

## 범위와 원화

- 실제 학습 저장, 계정·아동 전환, 실패·재시도, 서버 중복 방지, 부모 화면은 구현하지 않았다. 오늘의 학습은 저장 성공을 가정한 예시다.
- 배정 없는 날은 쉬는 날로 처리하고 누적을 유지하는 추천안을 표시한다.
- 2.5D 원화에 숨쉬기·등장 효과를 얹었다. 이동·먹이·탐험·자유 배치는 범위에 포함하지 않는다. 동작 줄이기 OS 설정을 따른다.
- 드래곤은 built-in `image_gen`으로 생성했다. [최종 원화](dragon-assets/dragons-v2.png)와 [프롬프트·보완 기록](dragon-assets/art-direction.md)을 함께 보관한다. 공간과 작은 소품은 CSS/SVG로 표현한 시안이다.
- 성장 단계와 시점은 확정했으며, 나머지 추천안은 계속 검토한다. 검토 의견은 `review.md`에 추가하고 합의한 항목만 `plan.md`의 확정 사항으로 옮긴다.
