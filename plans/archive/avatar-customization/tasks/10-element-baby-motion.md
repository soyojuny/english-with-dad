# 속성별 아기 움직임

사용자가 불·번개·얼음 눈 감기와 미세한 들숨 미리보기를 승인했다. `baby/element-preview.html`에서 각 속성을 비교할 수 있다. 원본 파일명과 실제 속성·눈 상태의 대응은 `assets/dragons/README.md`를 따른다.

승인된 픽셀 분리본을 `assets/dragons/source/baby/`에 이관하고 빌드로 1024px WebP를 생성했다. 1~17일의 각 속성 아기에 4초 호흡·6초 깜빡임을 연결하고 움직임 줄이기를 유지한다. 기존 무속성 동작·성장 및 DB 규칙은 그대로다. 새로운 에셋이 오프라인에서도 작동하도록 PWA 캐시를 v7로 갱신했다.

검증: 정식 PNG 6장과 승인 분리본 바이트 일치, WebP 6장 1024×1024·알파 확인. `npm run verify` 통과, 실제 브라우저에서 무속성·세 속성 파일 로딩과 18일 경계·움직임 줄이기 확인, 서비스 워커 하네스 및 실제 Next/PWA 4개 검사 통과. 실제 태블릿 성능은 미검증이다.
