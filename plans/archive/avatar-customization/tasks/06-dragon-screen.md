# 드래곤 전용 화면과 원화 연결

상태: 로컬 구현·검증 완료. 2026-11-04 사용자가 전용 화면 구성과 무료 꾸미기 추가를 승인했다.

## 사용자 요청

- 작은 팝업 꾸미기를 큰 화면으로 구성한다.
- 상단 요약 바 대신 읽기·DVD 기록 옆에 드래곤 진입 항목을 둔다.
- 준비된 알·기존 배경·장식을 실제 앱에 연결한다.

## 확정된 구현 계약

- 아동 화면의 `읽기·DVD 기록` 버튼 옆에 `드래곤` 버튼을 둔다. 기록 버튼의 기존 동작을 유지한다.
- 드래곤 버튼은 같은 앱 안의 전용 화면을 연다. 상단의 드래곤 요약 바와 꾸미기 dialog를 대체하고 `오늘의 학습으로` 이동을 제공한다.
- 전용 화면의 주 영역에 넓은 16:9 드래곤 공간을 배치한다. 태블릿 가로는 공간 옆에 꾸미기 도구, 좁은 화면은 공간 아래에 도구를 배치한다.
- 성장·보상·보유 드래곤 선택과 알/속성 선택을 이 화면에서 제공한다. 기존 성장·보상·자유 배치·저장·취소 규칙은 유지한다.
- 승인된 알 3종을 실제 알 선택·장면에 연결한다. 아기·청소년 및 미제작 속성 원화는 기존 표현을 사용하고, 승인된 불 성체는 신규 원화로 연결한다. 동작 7종 이식은 이번 범위에 포함하지 않는다.
- 용암 배경 4종과 석비·용암 수정을 기본 무료 항목으로 카탈로그에 추가한다. 기존 소품의 ID·획득 내역·배치·무료 여부는 유지한다. 둥지는 새 원화가 없으므로 기존 것을 유지한다. 새 소품은 선택·저장한 뒤 적용하며 기존 저장 배경을 임의로 바꾸지 않는다.
- 오늘 출시 준비를 위한 로컬 구현·검증까지 진행하며 원격 DB 적용·실서비스 배포·푸시는 별도 요청 범위다.

## 코드에서 확인한 제약

- 현재 읽기·DVD 기록은 탭이 아닌 기록 팝업을 여는 버튼이다. 인접 드래곤 버튼은 전용 화면 진입으로 구현하는 것이 기존 기록 흐름 변경을 줄인다.
- 기존 `DragonCompanion`이 맡던 상단 요약과 dialog를 `DragonScreen` 전용 화면으로 전환했다. `ChildActivityHeader`로 진입·복귀와 기록 버튼을 분리하고 `reading-manager-client.tsx`는 연결만 담당한다.
- 꾸미기 카탈로그는 DB `dragon_items`에서 제공한다. 새 배경·소품을 실제로 선택·저장하려면 카탈로그 추가 migration과 해당 art 렌더링이 필요하다.
- 기존 카탈로그는 초록 숲·이끼 둥지·들꽃과 보상 항목이다. 기존 ID의 의미를 용암 원화로 바꾸지 않는다.

## 구현 및 검증 순서

1. 전용 화면·진입/복귀·아동 전환 상태 분리 → 학습 화면과 기록 팝업 회귀, 로딩·오류·빈 상태 확인.
2. 알·불 성체·배경·소품 최적화 및 연결, 카탈로그 추가 → 원화 로딩, 기존 저장 호환, 무료 항목 소유·배치 서버 검증, PWA 계약 확인.
3. 큰 장면과 꾸미기 도구 배치 → 320·390·800·1280px에서 넘침·드래그·버튼 이동·저장/취소·전환 확인.
4. 관련 컴포넌트·브라우저·서버 검사와 `npm run verify` → 결과를 review.md에 기록하고 실제 적용 범위를 hand-off.md에 갱신.

## 액션 후속 계약

- 모든 액션은 아이가 눌러서 실행한다. 자동 액션은 이번에 추가하지 않는다.
- 스킬을 보상으로 획득하는 방식은 후속 작업이다. 획득 조건·보상 간 관계·해금 저장·단계/속성별 제공 액션은 아직 미정이다.
- 이번 작업에는 액션 버튼과 동작 7종 연결을 추가하지 않는다.
