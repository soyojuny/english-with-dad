# 첫 출시 원화와 꾸미기 정리

상태: 구현·원격 DB 반영·검증 완료 · 2026-11-04. 이 계약이 task 06의 둥지 유지·옛 카탈로그 노출·원화 일부만 연결 범위보다 우선한다.

## 확정된 요청

- 첫 출시이며 과거 데이터 호환을 위한 확장은 하지 않는다.
- 둥지 표시·선택·저장을 제거한다. 배치는 배경·장식 1·장식 2다.
- 준비한 용암 배경 4종을 썸네일로 고르고 석비·용암 수정 2종만 무료로 장식한다.
- 초기 배경은 용암 계곡, 초기 장식은 석비·용암 수정이다. 추가 소품을 위한 선택 기회는 계속 보관한다.
- 정식 원본은 `assets/dragons/source/`, 배포용 WebP는 `public/assets/dragons/`로 이관한다. `plans`는 제작 이력이며 운영 빌드가 읽지 않는다.
- 이미지 바이트·base64는 DB에 저장하지 않는다. ID·이름·art 식별자·선택/배치 좌표만 DB에서 관리한다.
- 아기 무속성·불·번개·얼음 원화도 연결한다. 액션 버튼·스킬 보상은 후속이다.

- [x] RPC 목록과 저장 ID 제한 → 미지원/잘못된 자리/네 번째 자리 거절, 소유자·버전 검사 유지.
- [x] 기본 알·아기·불 성체·배경·소품·후속 동작 원본 24개를 정식 폴더에 복사해 기준 위치로 승격 → 알파 유지 확인.
- [x] Sharp 직접 개발 의존성 고정, assets:dragons 및 prebuild 추가 → plans를 사용하지 않는 빌드와 WebP 24개 생성.

- [x] 최종 verify 및 검증·캡처 기록 마무리.

## 원격 적용의 안전한 범위

카탈로그 추가는 즉시 성공했다. 처음 작성한 일괄 배치 초기화/옛 항목 삭제안은 자동 승인 검토에서 실제 드래곤 행이 있다는 이유로 거절됐다. 거절된 작업을 실행하지 않고 해당 UPDATE/DELETE 및 제약 변경을 제거했다. 기존 행을 바꾸지 않는 기본값·조회 투영·명시적 저장 검증으로 바꾼 최종 migration을 로컬 DB 20개 검사 후 적용했다. 기존 행/버전이 그대로이고 명시적으로 저장할 때만 배치가 바뀌는 테스트를 포함한다. 데이터 초기화나 보상·성장 변경은 하지 않았다.

웹 서버 배포·커밋·푸시는 이번 작업에서 하지 않는다. 정적 이미지와 원본은 다음 앱 배포에 포함할 수 있도록 프로젝트 안에 준비한다.
