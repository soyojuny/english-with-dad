# 드래곤 체험형 시안

## 상태

제작 및 브라우저 검증 완료. 사용자 화면 검토 대기. 실제 앱 구현과 설계 합의는 미완료.

## 범위

- 독립 [HTML 시안](../dragon-world.html), CSS/JS, 드래곤 원화, [검토 가이드](../dragon-world-guide.md).
- 알 선택·부화·속성 확정·18일 청소년·성체·소품 선택과 배치·다음 알·기존 성체 재방문.
- 성장 시점 바로 보기, 속성별 성장 도감, 오늘의 학습 진입·자동 인정·완료 확인 예시.
- 앱 코드·데이터 계약·DB·PWA 캐시 수정 없음.

## 검증 기준

- 합의된 1일 부화·3일마다 소품 선택 기회·6일 속성 선택 가능·18일 청소년·30일 성체 경계를 확인한다. 18일 단계는 시안 제작 이후 2026-10-26 검토에서 확정했다.
- 보상 기회가 누적되고, 보유 소품 재배치에 기회를 다시 소비하지 않는다.
- 확인 버튼 없이 자동 인정하며, FAIL 결과도 인정하고, 중복 확인·이후 기록 수정으로 인정된 성장이 바뀌지 않는다.
- 새 알은 0일부터 시작하고 전체 보상 누적과 보유 소품은 유지한다. 기존 드래곤의 꾸밈은 바뀌지 않는다.
- 소품 선택 기회가 없거나 알 선택 전에는 보상 소품을 받을 수 없다.
- 데스크톱·태블릿·모바일에서 그림과 텍스트가 잘리지 않고 기본 흐름을 조작할 수 있다.

## 후속

사용자가 시안을 보고 외형·소품·수집 흐름을 구체화한다. 18일 청소년 단계는 확정했으며, 나머지 추천안은 승인 전 확정 사항으로 승격하지 않는다.

첫 학습 완료 전 알 선택이 가능한 현재 시안은 이후 확정된 0일 규칙과 다르다. 앱 구현 전에 첫 완료 → 알 선택 가능 → 선택 이후 다음 달성일에 부화·성장 1일로 이어지는 흐름을 시안에 반영해야 한다.
