# Step 02 — 로컬 표지 처리 도구

## What to Build

스킬의 `scripts/`에 Node/Sharp 로컬 표지 처리기를 추가한다. 파일명은 기존 계획
링크 유지를 위해 남기지만 앱과 공유하는 모듈은 만들지 않는다.

## Acceptance Criteria

- [x] 브라우저/DOM/canvas 없이 실행.
- [x] 기존 기본값으로 방향·비율·흰 배경·확대 방지·메타데이터 제거 수행.
- [x] 사용자 입력 표지를 덮어쓰거나 자르지 않고 압축 결과와 해상도·바이트·해시 반환.
- [x] 빈 파일·비이미지·손상 파일·파일/픽셀 상한 초과 거부.
- [x] 앱 모듈·의존성·설정 변경 없음.

## Required Verification

스킬 내부 테스트에서 고정 합성 이미지를 사용해 정상·경계·잘못된 입력을 검사한다.
압축 결과의 해상도·포맷·바이트와 원본 보존을 확인한다.
