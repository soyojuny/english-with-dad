# Step 03 — 단일 배치 명세와 Prepare

## What to Build

에이전트가 작성하는 단일 JSON 명세를 입력받아 저장 후보와 날짜별 배정안을 생성한다.
기존 `plan-assignments.mjs`는 수정하지 않고 호출한다. DB 연결·쓰기 기능은 넣지 않는다.

## Acceptance Criteria

- [x] 신규/기존 책, 사용자 입력 표지, 제목·시리즈·오디오 필드, 아동/루틴 역할,
  명시적 책 순서와 1/2주를 단일 명세에 기록.
- [x] 등록만 요청한 경우 배정 없이 준비 가능.
- [x] 기본 루틴과 부모가 지정한 책별 예외를 구분하고 결과에 고정.
- [x] 필수 오디오·HTTP(S) URL·공용 링크 확인·중복 ID·책 수·날짜·사진 검사.
- [x] 날짜별 제목·활동·횟수·퀴즈와 이미지 메타데이터를 사람이 읽을 수 있게 출력.
- [x] 저장용 data URL은 로컬 파일에만 기록. stdout에는 요약과 경로만 출력.
- [x] 명세와 산출물의 바이트 길이·SHA-256 검사 가능.
- [x] 출력 경로가 이미 있으면 거부하고 원본을 보존.

## Required Verification

스킬 내부 테스트로 등록만, 1/2주, 두 아동, 순서, 예외, 잘못된 URL/필드,
중복 ID, 누락 사진, 잘린 JSON, 산출물 변조와 CLI 출력을 검사한다.
