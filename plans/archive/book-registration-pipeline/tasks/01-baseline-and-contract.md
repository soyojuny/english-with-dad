# Step 01 — 스킬 범위와 로컬 계약 확정

## What to Build

사용자가 바로잡은 스킬 전용 범위를 명문화한다. 기존 앱의 처리·저장 규격을 읽고
로컬 도구의 기본값으로 유지한다. 앱 표시 크기·운영 DB 용량 측정은 하지 않는다.

## Acceptance Criteria

- [x] 앱/API/DB/기존 실행 코드 변경을 범위에서 제외.
- [x] JPEG, 최대 960px, 품질 72, 흰 배경, 확대 없음으로 로컬 기본값 확정.
- [x] 표지 외곽 맞춤은 사용자가 맡고 스킬은 입력 파일 보존·압축만 수행.
- [x] 기존 `books.cover` data URL 유지. Storage와 새 저장 경로 없음.
- [x] 스킬 내부에서만 도구·의존성·테스트를 관리.
- [x] 동시성·재시도를 새 시스템으로 개발하지 않고 기존 조회·검증 절차로 유지.

## Required Verification

`lib/cover-image.ts`와 기존 등록 스킬을 읽고 `review.md`에 근거를 기록한다.
범위 밖 파일의 변경 전후 해시를 비교한다.
