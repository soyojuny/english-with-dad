# Phase 2 / Step 04 — 화면 연결과 배정 선택 복원

## What to Build

먼저 선택 복원과 완료 버튼 표시 조건을 테스트한다. Step 02/03의 로직을 전용 hook과 아동 task UI에 연결한다. 배정 선택은 소유자·아동·날짜별로 sessionStorage에 보관하고 로딩 완료 후 유효한 값만 복원한다. 저장 중/오류/결과 확인 중 상태를 지속적으로 표시한다.

## Acceptance Criteria

- [ ] RED: 오늘의 첫 배정이 아닌 선택을 재로드 후 복원한다.
- [ ] 삭제된 배정, 다른 소유자/아동/날짜의 선택은 적용하지 않는다.
- [ ] 로딩 전에 저장된 선택을 첫 배정으로 덮어쓰지 않는다.
- [ ] 완료 버튼은 실행 기록과 목표 횟수에 따른 기존 수동 완료 규칙을 유지한다.
- [ ] 저장 중에는 연타를 막고, 저장 실패/미확정 상태는 task에서 보인다.
- [ ] 로딩 오류는 기록 없음과 구별한다.
- [ ] 복귀 이벤트와 늦은 응답은 활성 프로필에만 적용한다.
- [ ] 읽기/정따/단어 읽기 및 스스로 읽기/필사의 기존 횟수·시간 규칙을 유지한다.
