# 검토

- 앞선 대화에서 관찰 놀이와 독립 미리보기 구성이 승인되었다.
- 앱 획득 규칙은 기존 날기·꼬리 공격의 드래곤별 선택 기회 1개 관례를 따른다.
- `npm run verify` 통과: 계약·SW·PWA 검사, 단위 테스트, 타입 검사, 프로덕션 빌드.
- 관련 컴포넌트 검사 통과: 분신·기능 획득·꼬리 공격·이동의 기존 동작. DB 검사 63개 통과: 모든 migration을 적용한 PGlite에서 기존 기능과 공존·차감·성장 후 재시도·잘못된 자격·소유권·직접 갱신 거절 확인.
- 실제 개발 쇼케이스의 Chromium 검사 통과: 1024×768, 768×1024, 1180×820, 820×1180 및 390×844에서 가로 넘침 없음·세 선택지의 터치 영역과 경계 확인. 두 난이도의 자세·깜빡임, 오답 유지·단서 재확인·정답·일시정지·종료·성장 전환 확인. 성공 화면 캡처는 저장하지 않았다.
- WebKit은 현재 Playwright 버전에 맞는 실행 파일이 없어 실행하지 못했다. 실제 태블릿 장치 검사는 하지 않았다.
- 운영 DB migration 적용·배포는 하지 않았다. 쇼케이스는 DB 변경 없이 개발 모드에서 체험할 수 있다.

## 후속 요청: 원래 장면 안에서 분신 찾기

- 별도 놀이 화면과 카드·번호 표시를 제거했다. 기존 장면 DOM·배경·장식을 유지하고 분신을 같은 장면 위에 배치한다. 안내와 버튼은 장면 아래에 둔다.
- 새 문제에서 세 드래곤의 위치를 무작위로 만들며, 단서 다시 보기에서는 위치와 제거한 분신을 유지한다. 시작 후 장면을 화면 안으로 스크롤해 드래곤들이 바로 보이게 한다.
- 102개 재현 가능한 배치로 경계·터치 영역 분리·반복 난수 fallback을 검사했다. 관련 컴포넌트 67개와 `npm run verify`가 통과했다.
- Chromium에서 1024×768, 768×1024, 1180×820, 820×1180, 390×844를 확인했다. 원래 장면과 크기·배경 유지, 카드 없는 세 배우의 화면·장면 내부 배치, 서로 겹치지 않는 44px 이상 터치 영역을 검증했다. 실제 드래곤 터치로 오답·정답, 위치 유지·새 배치, 일시정지·Escape 종료·초점 복귀를 확인했다.
- 개발 서버와 빌드 검사의 `.next` 충돌을 피하기 위해 최종 브라우저 검사는 현재 소스를 `/tmp/ewd-clone-showcase-g1zoyp5v`에 복사한 독립 개발 서버(127.0.0.1:3001)에서 실행했다. 성공 화면 캡처는 저장하지 않았다.

## 후속 요청: 무작위 난이도와 분신·정답 효과

- 난이도 선택과 수동 시작을 제거했다. 새 놀이는 두 난이도 중 하나·진짜 자리·배치를 무작위로 정한다. 단서 다시 보기는 같은 난이도·배치·제거 기록을 유지한다.
- 단서 동작 5.2초 한 번 → 소멸 0.6초 → 생성 0.6초 → 관찰 순서로 자동 진행한다. 전환 도중에는 선택을 막는다. 효과는 기존 이미지와 CSS로 표시하며 추가 이미지나 캐시 변경은 없다.
- 정답을 찾으면 진짜의 반짝임과 나머지 분신의 소멸을 1.2초 표시한 뒤 놀이를 종료하고 원래 대기로 돌아간다. 일시정지·화면 숨김과 움직임 줄이기를 유지한다.
- 관련 컴포넌트 70개 및 `npm run verify` 통과. 두 무작위 분기와 재생 경계, 생성 전 선택 차단, 성공 지연, 전환·성공 중 일시정지를 검사했다.
- 실제 쇼케이스 Chromium의 1024×768, 768×1024, 1180×820, 820×1180, 390×844에서 두 난이도, 소멸·생성의 중간 불투명도와 효과 표시, 원래 배경의 배치 경계, 단서 재확인 시 위치 유지, 터치 정답과 반짝임 후 자동 대기·초점 복귀를 확인했다. 성공 화면 캡처는 저장하지 않았다.

## 후속 요청: 번개 속성 지원

- 불·번개 아기 모두 같은 `clone`과 놀이 규칙을 사용한다. 속성별 기존 앉기·걷기·깜빡임 시트로 표시하고 쇼케이스에 번개 획득 선택지를 연결했다. 새 이미지·캐시 변경은 없다.
- `20261114130000_thunder_clone.sql`은 최초 획득 자격만 불·번개로 확장하고 기존 기록·차감·재시도·소유권·행 잠금·RLS를 보존한다. 운영 DB 적용·배포는 하지 않았다.
- 두 속성으로 매개변수화한 놀이·획득 컴포넌트 검사 42개와 PGlite DB 검사 66개, `npm run verify`가 통과했다.
- 실제 쇼케이스 Chromium에서 번개 1024×768, 768×1024, 1180×820, 820×1180 및 불 1024×768을 확인했다. 속성에 맞는 세 이미지 디코드, 두 난이도, 소멸·생성·선택 차단, 배치 경계/비겹침, 터치 정답·반짝임·각 속성의 대기 원화 복귀를 검증했다. 성공 화면 캡처는 저장하지 않았다.


## 아동 화면 운영 적용

- 아동 화면은 같은 `DragonScreen`과 놀이 컴포넌트를 사용한다. 별도 구현 대신 실제 아동 UI에서 불·번개 각각 1024×768, 768×1024의 획득·기회 1개 차감·재조회 후 유지·원래 배경의 놀이·오답/단서 재확인·정답 효과·대기 복귀를 검증했다. 브라우저 검사 4개 통과.
- `fire_clone`, `thunder_clone`을 앱이 사용하는 운영 프로젝트 `yocdammswepuwyvzydra`에 순서대로 적용했다. `skills` 제약·불/번개 자격·RLS·익명 실행 금지·인증 사용자 RPC 실행·직접 UPDATE 금지를 확인했다. 보안 advisors는 기존 경고에서 증가하지 않았다. 실제 아동의 보유 기능이나 보상 기회는 변경하지 않았다.
- manifest 안내와 SW·PWA 검사를 v26으로 맞췄다. 실제 Next의 설치 메타·자산 캐시·오프라인 문서·등록 실패 검사 4개와 `npm run verify`가 통과했다. 성공 화면 캡처는 저장하지 않았다.
- 이 저장소는 `origin/main` 커밋을 Vercel Production에 자동 배포한다. 반영에는 프로젝트의 git publish wrapper를 사용한다.
