# 불·번개 아기 분신 놀이

## 합의한 계약

사용자가 승인한 행동 관찰 규칙을 실제 앱과 개발 쇼케이스에 연결한다. 후속 요청에 따라 별도 화면 대신 원래 배경·장식이 있는 16:9 장면 안에서 진행한다. 세 드래곤을 칸 없이 무작위로 배치하고 직접 터치하며, 서로의 터치 영역과 장면 경계를 침범하지 않는다. 기존 불·번개 아기 원화를 재사용하고 세 마리의 행동을 관찰해 진짜를 선택한다. 매 놀이마다 앉기 또는 두 번 깜빡임 후 앉기를 무작위로 정하며 난이도 선택 UI는 없다. 단서 행동을 한 번 보여 준 뒤 소멸·생성 효과로 분신을 나타낸다. 정답을 찾으면 잠깐 반짝인 뒤 자동으로 원래 대기 모습으로 돌아간다. 시간 제한 없이 반복하며 오답 후 계속 선택하고 단서를 다시 볼 수 있다. 다시 보기는 같은 문제·위치·제거한 분신을 유지한다. 새로 놀기는 난이도·진짜·위치를 다시 섞는다.

기존 스킬 획득 관례를 따라 불·번개 아기(1~17일)에게 선택 기회 1개로 `clone`을 가르친다. 기존 소유권·잠금·중복 차감 방지를 유지한다. 놀이 결과와 난이도는 저장하지 않는다. 새 이미지는 추가하지 않는다. 사용자의 후속 아동 화면 적용 요청에 따라 운영 DB migration 적용·아동 화면 브라우저 검증·PWA 갱신과 main 자동 배포를 포함한다.

## 구현과 검증

1. 순수 동작 규칙과 독립 React 놀이 컴포넌트 → 동작 경계·재생·오답·정답·초기화 검사.
2. 타입·획득 UI·migration → 불·번개 아기 자격·차감·재시도·소유권·기존 스킬 공존 DB 검사.
3. 실제 장면과 쇼케이스 연결 → 이동/비행/공격 충돌 방지, 종료/성장/선택 변경, 태블릿 가로·세로 및 작은 화면 검사.
4. `npm run verify` 및 관련 컴포넌트·DB 검사. 기존 캐시 이미지를 재사용하므로 캐시 대상은 바뀌지 않는다.
