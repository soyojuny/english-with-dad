# 검토

## 구현

사용자가 확인한 1~17일 번개 아기·기회 1개·기존 breath 공유 범위를 구현했다. 기존 불 구현 위에 속성별 애니메이션 선택만 추가했다. 읽기 데이터 계약과 Supabase 응답 매핑은 변경하지 않았다. migration은 RPC의 최초 획득 조건만 확장하고 소유권·행 잠금·재시도·RLS를 유지한다. 운영 DB와 공개 배포는 실행하지 않았다.

11개 제공 시안에서 built-in image_gen으로 흰 배경을 분리했다. 마지막 빈 칸을 포함한 4×3 시트이며 잘린 12번은 제외한다. 정식 PNG·JSON·무손실 WebP를 추가했다. 밝고 어두운 배경에서 드래곤 경계·번개 효과를 확인했다. 생성형 분리 특성상 원본 RGB와 세부 윤곽에 미세한 차이가 있을 수 있다. 프롬프트와 원본·출력 SHA-256은 출처 JSON에 기록했다.

## 검증

- 컴포넌트·훅 48개 통과: 불·번개의 재생·상호 배제·앉기 후 시작·전환 취소·움직임 줄이기와 획득 UI.
- PostgreSQL/PGlite 81개 통과: 정상 습득·1/17일 경계·0/18일과 미지원 속성 거절·기회 부족·중복 차감 방지·성장 후 기록·소유권·직접 갱신 차단.
- Chromium 390/1280px 브레스·꼬리 공격 8개 통과: 획득·재조회·끝까지 재생·저장 기회 유지·움직임 줄이기·배치·발 접지·가로 넘침.
- 실제 Next/PWA 2개 통과: 새 시트의 캐시 준비와 오프라인 조회.
- 초기 전체 검증은 Next 페이지 수집의 일시적 /_document 모듈 누락으로 실패했다. 코드 변경 없이 재빌드는 통과했다. `npm run verify`를 다시 실행해 계약·SW·PWA·단위 검사·타입 검사·프로덕션 빌드 전체 통과를 확인했다.

정상·경계·잘못된 상태를 위 항목에 포함했다. 외부 Supabase 연결 없이 실제 migration을 로컬 PostgreSQL 엔진에 적용해 검사했으며 운영 적용과 다중 연결 잠금 경쟁 검증을 대신하지 않는다. 기존 파일의 다른 진행 중 변경은 보존했다.

## 최종 B안 화면 적용

A·B·C 비교 후 사용자의 명시적 B안 선택에 따라 qdm5w9 원본의 보라빛 12자세로 정식 시트를 교체했다. 비교 시안의 크기·발 기준과 2.69초 타이밍을 유지하고 움직임 줄이기는 7번 최대 발사 자세를 300ms 표시한다. 생성형 투명 분리 후 1737px 폭을 1736px로 맞춰 434×302px 칸 12개로 정리했으며 밝은/어두운 배경에서 흰 번개 중심·발광·윤곽을 확인했다. PNG·출처 JSON·배포 WebP와 캐시 v29를 함께 갱신했다. 원본 6·7번의 번개 끝 잘림은 유지한다.

B안 교체는 에셋·타이밍 변경이며 획득·저장 계약과 DB migration은 바꾸지 않았다. 기존 불 브레스도 그대로 재생한다. 정상 재생·마지막 12번 경계·미지원/미획득 상태·전환 취소를 포함한 컴포넌트/훅 48개, 아동 화면 390/1280px의 불·번개 브라우저 4개, 실제 PWA v29 캐시·오프라인 2개를 통과했다. 공개 배포와 운영 DB 반영은 실행하지 않았다.

최종 B안 상태에서 `npm run verify`의 계약·SW·PWA·단위 검사·타입 검사·프로덕션 빌드를 모두 통과했다.


## 원본 해상도·픽셀 복구

사용자 지적을 확인해 생성형 배경 분리가 형태를 바꾸고 820×570 자세가 434×302로 축소된 문제를 수정했다. 사용자 승인대로 생성형 도구를 사용하지 않고 원본 픽셀을 정수 이동만으로 다시 배치했다. 정식 시트와 무손실 WebP 모두 3280×1710(820×570 × 12칸)이며 빌드도 축소하지 않는다. 불투명 몸체/얼굴을 보존하고 흰 매트의 가장자리·잔광만 계산으로 분리한다. 밝은/어두운 배경에서 얼굴·비늘·발·번개 경계를 시각 확인했다.

115만 개 이상의 불투명 픽셀에서 원본 RGB 변경이 0이고 원본 몸체·얼굴 13개 영역의 RGBA 해시가 일치한다. PNG 디코딩 후 흰 배경 재합성 오차는 보이는 픽셀의 8비트 채널당 최대 1이다. 배포 WebP는 정식 PNG의 보이는 RGB·알파와 일치한다. 이 조건을 에셋 회귀 검사에 추가했고 정상 해상도·축소 재발·RGB/알파 변조 검출을 검토했다. 이 검사는 외부 입력을 받는 API가 아니므로 잘못된 입력 호출 사례는 적용하지 않는다.

기존 재생·획득·저장 계약은 바꾸지 않았다. 관련 컴포넌트/훅 48개, 모바일/데스크톱 브레스 브라우저 4개, PWA v30 캐시·오프라인 2개와 `npm run verify` 전체를 통과했다. 원본이 흰 배경에 합성되어 있어 잔광 알파에는 추정이 필요하고 매우 어두운 배경에서는 일부 밝은 경계가 남을 수 있다. 원본 번개 끝 잘림도 유지한다. 운영 DB 반영과 공개 배포는 실행하지 않았다.
