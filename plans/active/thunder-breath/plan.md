# 번개 아기 브레스 앱 연결

## 합의한 계약

2026-11-15 사용자가 범위를 확인했다. 번개 아기(1~17일)도 기존 `breath`를 선택 기회 1개로 배운다. 기존 불 브레스와 획득 기록·중복 차감 방지·성장 후 보존을 공유한다. 무속성·얼음·알·청소년·성체에는 신규 획득과 사용을 제공하지 않는다.

2026-11-15 후속 비교 후 사용자가 B안(qdm5w9 원본)을 선택하고 화면 적용을 요청했다. 비교 시안의 1~12번 자세와 시간(850,180,180,300,130,140,100,130,200,150,150,180ms)을 사용한다. 총 2.69초다. 흰 배경을 투명하게 정리하고 기존 아기 드래곤의 크기·발 위치에 맞춘다. 지상에서 일어서기→충전→발사→회복을 한 번 재생한다. 다른 스킬과 이동의 상호 배제·전환 시 취소·움직임 줄이기 300ms는 기존 불 브레스 규칙을 공유한다. 움직임 줄이기 대표 자세는 B의 7번 최대 발사다. 기존 습득 기록·DB 계약을 그대로 사용한다.

## 검증

1. 정식 PNG·출처 JSON·배포 WebP: 프레임·투명 경계·크기·발 위치 확인.
2. 앱 지원 조건·RPC migration: 1/17일 허용, 0/18일·다른 속성 거절, 기회 차감·재시도·소유권 검증.
3. 아동 화면: 획득·재조회·재생·동작 취소·움직임 줄이기, 모바일/데스크톱 브라우저 확인.
4. 캐시 v30에 시트 추가, 관련 검사와 npm run verify.

공개 배포와 운영 DB 적용 여부는 구현 결과에 별도로 기록한다.

## 원본 화질 복구 계약

사용자가 생성형 재처리 없이 원본 해상도와 그림을 보존하고 배경만 분리하는 수정을 승인했다. 원본 RGB를 정수 이동만으로 820×570px 12개 칸에 배치하고 3280×1710 PNG와 같은 크기의 무손실 WebP를 사용한다. 불투명 몸체 RGB는 유지하고 흰 매트가 섞인 가장자리·잔광만 계산으로 분리한다. 흰 배경 재합성 오차·몸체 RGB 보존·발 정렬·원래 재생·캐시 갱신을 검증한다.
