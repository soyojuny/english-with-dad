# 실제 배정 시험

## What to Build

부모가 지정한 아동·책·시작 일요일·기간으로 현재 루틴을 적용한 할일을 배정한다.
새 책 사진을 제공하면 등록부터 이어서 처리하고, 기존 책이면 재사용한다.

## Acceptance Criteria

- [x] 아동 ID와 부모 소유, 책 순서와 필요한 링크 확인.
- [x] 현재 루틴으로 날짜별 저장 후보를 생성하고 기존 배정 충돌 조회.
- [ ] 요청한 배정만 저장하고 행 재조회로 소유·날짜·활동·횟수·퀴즈 검증.
- [ ] 부모가 앱에서 할일 표시와 오디오 실행 확인.
- [ ] 배정 ID와 검증 결과를 기록.

## Required Verification

저장 전후 Supabase 조회, 생성 후보와 실제 행의 비교, 실제 앱 화면 확인.
로그인 세션 없이 실행한 로컬 화면 검증은 실제 앱 검증과 구분한다.
