# 불 아기 브레스 검토

## 결과

승인 시안의 11프레임을 정식 PNG·출처 JSON·무손실 WebP로 등록하고 아이 화면과 쇼케이스에 연결했다. 불 아기에게 선택 기회 1개로 `breath`를 저장한다. 승인된 위치·크기·타이밍을 유지하고 배경 합성을 위한 흰 매트와 경계 오염만 분리했다. 앱에서는 서기와 높이·접지를 맞췄다. WebP는 1,914,956바이트이며 3040×1680px PNG와 전체 알파·보이는 RGB가 일치한다.

## 검증

- `npm run verify`: 계약·SW·PWA·전체 unit·TypeScript·Next 프로덕션 빌드 통과.
- 관련 component/hook 4파일 42테스트 통과. 재생 프레임·타이밍·종료·앉기에서 일어서기·행동 충돌·자격·선택/성장/꾸미기/일시정지/백그라운드 취소·움직임 줄이기를 확인했다.
- `tests/server/dragon-db.test.ts`: PGlite에서 전체 migration과 76테스트 통과. 다른 기능 공존·정확히 1회 차감·기회 부족·성장 후 재시도·1/17일 허용·0/18/30일과 다른 속성 거절·다른 아동/소유자·직접 수정·중복/null 제약을 확인했다. 함수 입력은 타입과 기존 RPC 경계를 따르며 임의의 불가능한 hook 인자는 만들지 않았다.
- client HTTP 브라우저 6테스트 통과: 불 브레스와 불/번개 꼬리 공격을 390px·1280px에서 확인했다. 실제 이미지 해석·저장 응답 후 버튼 제공·재조회·종료·움직임 줄이기·가로 넘침을 검사했다. RPC는 대역이며 실제 DB 검증과 구분한다.
- 실제 Next/PWA 4테스트 통과: manifest/icon·v27 캐시 목록·브레스 WebP 오프라인 응답·worker 등록 실패 안내를 확인했다.
- 어두운 배경 합성에서 기존 서기와의 높이·접지 및 흰 테두리 보정을 시각 확인했다. 성공 브라우저 스크린샷은 저장하지 않았다.

## 남은 제한

원본에서 잘린 불꽃과 매우 옅은 연기 손실은 남는다. 운영 Supabase CLI/MCP 연결이 없어 운영 migration/advisors 검사는 수행하지 않았다. `20261115120000_fire_breath.sql`은 로컬 DB에서 검증했고 운영 DB 적용·커밋/푸시·공개 배포는 수행하지 않았다. 기존 tmp_dragon 삭제 변경은 이번 작업 범위에 포함하지 않았다.
