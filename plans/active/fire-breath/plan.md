# 불 아기 브레스 앱 연결

## 합의한 계약

사용자는 2026-11-15에 승인한 11프레임 시안을 아이 화면에 연결하고 선택 기회로 획득하도록 요청했다. 기존 기능 관례를 따라 불 아기(1~17일)에게 기회 1개로 `breath`를 가르친다. 습득 기록은 성장 후에도 보존하고 같은 요청을 재시도해도 다시 차감하지 않는다. 무속성·번개·얼음과 알·청소년·성체는 신규 획득하거나 사용할 수 없다. 종전의 청소년 브레스 계획은 이번 불 아기 승인 범위에 한해 갱신한다.

지상에서 버튼을 누르면 앉은 자세부터 일어서고 승인한 1~11번을 원래 타이밍으로 한 번 재생한 뒤 일반 대기로 돌아온다. 브레스 중 이동·날기·꼬리 공격·분신·재시작을 막는다. 선택·성장·꾸미기·백그라운드·일시정지 전환은 재생과 대기 요청을 취소한다. 움직임 줄이기는 최대 불꽃 자세 한 장을 300ms 표시한다. 배경 합성을 위해 승인본 흰 매트를 투명하게 분리한다. 원본 불꽃 잘림은 보존한다.

## 검증 순서

1. 정식 PNG·출처 JSON·WebP → 크기·프레임 순서·투명 경계·앱 배치 확인.
2. 타입·획득 UI·마이그레이션 → 자격 경계·기회 차감·재시도·기존 기능 공존·RLS 확인.
3. 장면·쇼케이스 → 재생 종료·충돌 방지·취소·390px/1280px 브라우저 확인.
4. PWA 캐시 v27 및 `npm run verify`, 관련 컴포넌트·DB 검사.

현재 요청은 구현 범위다. 운영 DB 반영과 공개 배포 여부는 결과에 명시한다.
