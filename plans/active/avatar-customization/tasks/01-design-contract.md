# 설계 합의

## 상태

진행 중.

## 완료 기준

- 보상 단위, 지급 조건, 인정할 학습 범위를 합의한다.
- 드래곤 외형과 성장·꾸미기·획득·표시 흐름을 합의한다.
- 기존 기록과 기록 수정 등 경계 사례를 정리한다.
- 구현 작업과 검증 기준을 계획에 반영하고 사용자와 설계 합의를 확인한다.

## 확정 사항

- 학습 보상형: 기본 꾸미기를 제공하며 학습 완료로 새 소품을 해제한다.
- 하루 목표 달성일 누적: 첫 완료일은 알 선택권을 주는 0일이다. 알 선택 이후의 다음 달성일부터 성장·소품 보상에 하루씩 누적하고, 쉬는 날에도 누적을 유지한다.
- 하루 달성 판정: 아동 화면에 표시되는 활성 배정의 모든 학습 목표 횟수를 채우고, 해당 배정의 모든 퀴즈 결과를 기록한다. PASS·FAIL 모두 완료로 인정한다.
- 달성 유지: 한 번 인정된 달성일과 성장·보상은 이후 배정 추가·변경이나 학습 기록 수정에도 유지한다. 학습 기록 자체는 수정된 내용을 따른다.
- 시작 기준: 첫 알을 선택한 당일은 0일로 두고 이후의 다음 달성일부터 성장·전체 소품 보상 달성일을 1일로 누적한다. 알 선택 전 학습의 소급 반영은 하지 않으며 기존 학습 기록은 보존한다.
- 소품 선택 기회 지급: 알 선택 이후 전체 소품 보상 누적 3·6·9·12일 등 3일 달성마다 1회. 소품은 아이가 선택할 때 획득한다. 첫 하루 목표 달성에는 알 선택권 외의 소품 선택 기회가 없고 주간 초기화도 없다.
- 소품 선택: 미보유 소품 목록에서 아이가 원하는 것 1개를 고른다. 획득 전에도 목록을 볼 수 있다.
- 꾸미기 범위: 첫 버전은 배경·둥지·주변 장식으로 공간을 꾸민다. 몸에 착용하는 장비는 후속 확장으로 둔다.
- 소품 공유: 아이별 보유 소품을 같은 아이의 모든 드래곤에서 사용한다. 꾸미기 설정은 드래곤마다 따로 유지한다.
- 배치 조작: 첫 버전은 소품을 선택해 정해진 자리에 놓는다. 자유 배치 확장 시 보유 목록과 배치 설정을 구분해 변경 범위를 한정하는 설계 의견을 계획에 기록했다.
- 선택 기회 누적: 선택을 미뤄도 기회는 기한 없이 누적하며, 학습과 드래곤 성장을 막지 않는다.
- 완료 확인: 아이가 완료한 학습·남은 학습과 오늘 달성 인정 여부를 확인할 수 있어야 한다. 상세 설계와 검증 기준은 [아이의 완료 확인](02-completion-confirmation.md)에 기록한다.
- 확인 동작: 아이가 ‘오늘 완료 확인’을 누르면 저장된 학습을 점검하고 부족한 항목을 안내한다. 버튼 자체로 학습 횟수를 늘리거나 퀴즈를 완료 처리하지 않는다.
- 확인 목적: 하루 학습을 마칠 때 당일 누락을 발견하고 해당 학습으로 이동해 마무리한다. 사후 기록 보완을 통한 소급 인정 정책은 추가하지 않는다.
- 자동 인정: 저장된 학습이 조건을 충족하면 첫날에는 알 선택권을, 이후에는 성장·소품 보상 자격을 자동 반영한다. 확인 버튼은 재확인용이며 필수가 아니다. 알·소품 선택은 별도 동작이다.
- 기본 캐릭터: 사람이 아닌 2.5D 드래곤. 첫 하루 목표 달성으로 알 선택권을 얻고, 알 선택 이후의 첫 달성일에 부화한다. 달성일마다 성장 진행도가 쌓이며 1일 부화·18일 청소년·30일 성체로 외형이 변한다. 6일부터 속성을 선택할 수 있고, 선택을 미뤄도 성장 단계는 계속 진행한다.
- 첫 버전 종류: 시안처럼 드래곤 한 종류에 불·번개·얼음 세 속성을 제공한다. 체형·얼굴·날개 등 생김새가 다른 종류는 이후 추가한다.
- 알 선택: 무늬가 다른 알 3개 중 하나를 고른다. 모두 같은 종류로 부화하며 알 무늬는 이후 속성 선택에 영향을 주지 않는다.
- 부화 전 미리보기: 알 선택 화면에서 부화할 무속성 아기의 모습을 보여주고, 아이가 어떤 드래곤을 키울지 확인한 뒤 고르게 한다. 원화의 구체적인 표현은 계속 검토한다.
- 순차 수집: 첫 드래곤이 성체가 되면 다음 알을 얻으며 기존 드래곤은 보유한다.
- 성체 도달: 알 선택 이후의 다음 달성일부터 한 마리당 하루 목표 달성일을 누적하여 30일 달성 시 성체가 된다. 첫 알 선택권을 얻은 0일은 제외한다. 주 6일 달성 시 육성 시작 후 약 5주다.
- 육성 완료: 성체 완성 연출과 함께 다음 알을 받는다. 성체는 계속 보유하고 다시 보거나 보유 소품으로 꾸밀 수 있다.
- 다음 육성: 다음 알 선택 이후의 다음 달성일부터 성장일을 새로 누적한다. 선택을 미뤄도 아이의 전체 소품 보상 달성일은 계속 누적하며, 사이의 달성일을 새 드래곤 성장에 소급 반영하지 않는다.
- 속성 획득: 각 드래곤의 누적 6일 달성 시 아이가 불·번개·얼음 중 하나를 고르는 별도 보상으로 제공하며 3일 달성 소품도 유지한다.
- 성장과 선택 분리: 성장은 하루 목표 달성일 누적으로 자동 진행한다. 소품·속성 선택을 미뤄도 성장과 30일 성체 도달을 막지 않으며, 속성 선택은 소품 선택 기회를 소비하지 않는다.
- 속성 선택 전후 외형: 선택 전에는 현재 성장 단계의 무속성 모습을 사용한다. 청소년·성체 이후를 포함해 나중에 속성을 선택하면 성장일·단계를 유지하고 현재 단계에 선택한 속성을 적용한다.
- 속성 고정: 드래곤당 하나이며 변경·추가할 수 없다. 다른 속성을 원하면 새 드래곤을 키운다.
- 화면 배치: 학습 화면 상단에 작은 드래곤과 성장·다음 소품 보상 진행을 표시한다. 드래곤을 눌러 큰 모습·꾸미기·모아보기를 열고, 학습 목록 끝에서 오늘 완료 확인을 실행한다.

## 진행 기록

- 후속 확장 요구: 색상뿐 아니라 생김새가 다른 드래곤 종류를 추가한다. 종류와 속성을 구분하며, 종류별 알·획득 방식·제공 수는 후속 설계 항목으로 남긴다.
- 요청에 따라 사람 캐릭터의 세 그림체 HTML 비교 샘플을 작성하고 정면 2.5D 예시를 추가했다. 이 샘플은 드래곤 시안으로 전환한 뒤 사용자 요청으로 삭제했다.
- 데스크톱·모바일에서 사람 캐릭터 샘플의 렌더링과 옷 색·소품 조작을 확인했다.
- 이후 사용자는 2.5D 드래곤을 키우는 방향으로 변경했다. 제공한 불 드래곤·폭풍 와이번 참고 이미지를 직접 확인하고 계획에 관찰 내용을 기록했다.
- 알 선택 → 부화 → 성장과 단계별 외형 변화를 합의했다. 단순 성장 외의 재미 요소를 논의 중이다.
- 비밀 알과 속성·수집 방식을 비교한 뒤 성체 달성 시 다음 알을 얻고 기존 드래곤을 보유하는 순차 수집을 합의했다.
- 속성은 별도 성장 보상으로 선택하며 한 마리당 하나로 고정한다. 새 속성을 얻으려면 새 드래곤을 키우는 것으로 확정했다.
- 2026-10-25: 사용자의 화면 중심 검토 요청에 따라 [드래곤 체험형 시안](../dragon-world.html)을 제작했다. [체험 가이드](../dragon-world-guide.md)에 추천안과 검토 질문을 모았다. 사용자 화면 검토와 설계 합의는 진행 중이며 앱 구현은 시작하지 않았다.
- 후속 정정: 첫 완료일은 알 선택권을 주는 0일이며, 알 선택 이후의 다음 달성일부터 성장·소품 보상을 누적한다. 외형은 매일 바뀌지 않고 정해진 단계에서 변한다. 체험형 시안은 이전 시작 순서로 남아 있다.
- 2026-10-26 검토: 성장과 보상 선택의 분리, 속성 미선택 중 자동 성장, 3일마다 소품 선택 기회 지급을 명확히 했다. 보상 소품 8종은 초안으로 유지하며 자정 경계의 별도 정책은 추가하지 않는다. 첫 학습 완료 후 알 선택을 재확정했고 시안 수정은 후속으로 남겼다.
- 2026-10-26 후속 합의: 1일 부화·6일 속성 선택 가능·18일 청소년·30일 성체를 확정했다.
