# 아이의 완료 확인

## 상태

설계 중. 앱 구현은 시작하지 않았다.

## 사용자 요구

아이는 완료했다고 생각하지만 실제로 남은 학습이나 저장되지 않은 완료가 있을 수 있다. 아이가 완료 여부와 남은 항목을 직접 확인할 수 있어야 한다.

저장된 학습이 하루 달성 조건을 충족하면 첫 완료일에는 알 선택 자격을, 알 선택 이후의 다음 달성일부터 성장·소품 보상 자격을 자동 반영한다. 아이가 ‘오늘 완료 확인’ 버튼을 누르면 남은 학습과 달성 인정 여부를 다시 확인한다. 버튼을 누르는 것은 달성 인정의 필수 조건이 아니다.

버튼의 목적은 아이가 하루 학습을 마칠 때 빠진 항목을 찾아 그 자리에서 마무리하도록 돕는 것이다. 부모의 사후 기록 보완으로 달성을 소급 인정하는 별도 정책은 이번 기능에 추가하지 않는다.

‘오늘 완료 확인’ 버튼은 학습 목록 끝에 배치한다. 학습 화면 상단에는 드래곤과 성장·다음 보상 진행을 표시하며, 드래곤을 누르면 큰 모습 보기·꾸미기·모아보기를 연다.

## 현재 확인한 사항

- 아동 화면은 오늘 전체 완료 횟수, 배정별 진행률, 선택한 학습의 목표 횟수를 표시한다.
- 개별 완료 저장에는 저장 중·결과 확인·실패·재시도 안내가 있다.
- 드래곤의 하루 달성·성장·보상 반영 확인은 새로 연결해야 한다.

## 구현 시 검증 기준

- 마지막 학습·퀴즈의 저장으로 조건을 충족하면 확인 버튼을 누르지 않아도 첫 완료일에는 알 선택권을, 이후에는 성장·소품 보상 자격을 한 번 반영한다. 알·소품 선택은 별도 동작이다.
- 첫 완료일은 0일로 표시한다. 알을 선택한 당일은 성장·소품 보상에 세지 않고, 선택 이후의 다음 달성일부터 1일로 표시한다.
- 소품·속성을 선택하지 않아도 하루 목표 달성일에 따라 자동 성장하며 30일에 성체가 된다. 전체 소품 보상 누적 3·6·9일마다 선택 기회가 1회씩 쌓이고, 선택 전에는 소품을 획득한 것으로 표시하지 않는다. 속성 선택은 소품 선택 기회를 차감하지 않는다.
- 드래곤별 누적 1일에 부화하고 6일에 속성 선택을 연다. 17일에는 아기 단계를 유지하고 18일에 청소년으로 바뀌며, 29일에는 청소년을 유지하고 30일에 성체가 된다. 속성 미선택 상태에서도 같은 성장 경계를 적용한다.
- 속성 미선택 시 각 성장 단계의 무속성 모습을 표시한다. 18일 청소년이나 30일 성체에서 뒤늦게 속성을 선택해도 성장일·단계·소품 선택 기회는 그대로 유지하고 현재 단계에 선택한 속성을 적용한다.
- ‘오늘 완료 확인’ 버튼으로 저장된 오늘 학습을 점검할 수 있다. 미완료 항목이 있다고 확인 동작을 막지 않으며, 부족한 항목을 안내한다.
- 확인 버튼 자체는 학습 완료 횟수를 증가시키거나 퀴즈 결과를 대신 입력하지 않는다.
- 목표 2회 중 1회만 저장된 경우 책·학습명과 남은 1회를 확인하고 해당 학습으로 이동할 수 있다.
- 배정된 퀴즈의 결과가 없으면 미입력 항목으로 안내한다. PASS·FAIL 모두 기록 완료로 인정한다.
- 완료 저장이 지연되거나 응답이 유실되면 저장 확인 중으로 표시하고, 단순 미완료나 성공으로 단정하지 않는다. 결과 확인·동일 요청 재시도 과정에서 학습을 다시 수행하도록 요구하지 않는다.
- 학습은 모두 저장됐지만 달성·성장 반영이 지연되면 두 상태를 구별해서 설명한다. 이미 저장한 학습을 미완료로 표시하지 않는다.
- 달성 인정과 성장·보상 저장을 확인한 뒤 완료를 표시하며, 화면을 다시 열거나 새로고침한 뒤에도 인정 상태를 확인할 수 있다.
- 재조회·재시도·재접속으로 같은 날짜의 성장·보상을 중복 지급하지 않는다.
- 데이터 로딩·조회 오류·할 일 없음에서 `0/0`을 오늘 달성으로 오인하지 않는다.
- 달성 후 추가된 배정은 새로 남은 학습으로 설명하되 이미 인정된 달성일과 성장·보상을 유지한다.
- 모바일에서 진행·남은 항목·저장 상태·달성 인정 상태가 겹치거나 잘리지 않는다.
- 학습 목록 끝에서 완료 확인을 실행하고 남은 항목으로 이동할 수 있다. 드래곤 상세 화면에 들어가지 않아도 완료 확인이 가능하다.

## 미결정 사항

- 상세한 문구·확인 결과 화면 구성·축하 연출.
