- 사용자 확정: 속성 선택 전에는 현재 성장 단계의 무속성 모습으로 성장한다. 청소년·성체 이후에 선택해도 성장일과 단계를 유지하고 현재 단계에 선택한 속성을 적용한다. 원화의 구체적인 표현은 계속 검토한다.
- 사용자 확정: 첫 버전은 시안처럼 드래곤 한 종류에 불·번개·얼음 세 속성을 제공한다. 체형이 다른 종류는 이후 추가한다.
- 사용자 확정: 무늬가 다른 알 3개 중 하나를 선택하고 모두 같은 종류로 부화한다. 알 무늬는 속성을 결정하지 않으며, 속성은 누적 6일 이후 별도로 선택한다. 부화 전 모습 공개 여부는 계속 검토한다.
- 계획·설계 합의 task·완료 확인 검증 기준·용어집에 합의 내용을 반영했다. 앱 코드와 체험 시안은 수정하지 않았다.

## 후속 의견 · 드래곤 종류 다양화

- 와이번형·동양 용형 등은 후보 예시다. 첫 버전은 한 종류와 세 속성으로 확정했다. 추가 종류의 알·획득 방식·제공 수·속성 조합은 미정으로 남겼으며, 현재 시안이나 앱 구현을 확장하지 않았다.

### Standards 검토

`code-review` 스킬의 두 축을 적용했다. 이 저장소의 사용자 지침이 명시적 요청 없는 subagent 사용을 제한하므로 직접 검토했다. 기준은 작업 시작 HEAD 대비 이번 작업 파일이며, 기존 `docs/CONTEXT.md` 변경과 첨부 이미지 삭제는 제외했다.

- 아동 메인 파일은 연결만 추가하고 드래곤 UI·동작·저장 모듈은 분리했다. 120,000-byte 예산과 계약 검사를 통과한다.
- 새 공개 테이블 RLS, 소유권 FK, 읽기 전용 권한, 내부 함수 실행 취소, 빈 search_path, RPC 입력 검증을 확인했다. 보상 원장을 클라이언트가 직접 고치지 못하도록 definer 사용 이유를 문서화했다.

- 남은 차단 사항 없음. 실제 다중 DB 연결의 잠금 경쟁과 Supabase advisor는 로컬 단일 연결 테스트로 대체하지 않는다.
