# 검토 기록

## 2026-11-01

- 사용자 요청: 기존 한글책·영어 그림책 기록과 함께 아동 DVD 시청 기록을 추가하는 계획을 검토한다.
- 사용자 확정: DVD 목록은 공통이며 보유하거나 보는 DVD를 추가하고 안 보는 DVD를 뺄 수 있다.
- 사용자 확정: 시청 시간은 30분부터 90분까지. 최초 요청의 10분 단위를 적용해 30·40·50·60·70·80·90분으로 정리했다.
- 사용자 동의로 채택: 부모가 공통 목록을 관리하고 보는 중인 항목만 아동에게 노출한다. 제외한 DVD의 과거 기록은 보존한다.
- 사용자 확정: 기존 기록 팝업을 책 읽기·DVD 시청 탭으로 확장한다.
- 사용자 추가 요구: 아동의 책 읽기 시간 입력도 드롭다운으로 변경하고 DVD와 동일한 30~90분 범위를 제공한다. 최초 요청대로 10분 단위를 유지한다.
- 해석: ‘기본 30분부터’에 따라 두 탭 모두 기본 선택을 30분으로 정리했다. 기존 저장 기록의 시간은 변경하지 않는다.
- 확인: 현재 타입·부모 수기 입력·부모 활동표에는 DVD 기록이 있지만 공통 DVD 목록은 없다.
- 확인: 부모 화면의 읽기 시간 합계는 현재 모든 활동 시간을 포함한다.
- 사용자 확정: DVD 시청 시간과 읽기 시간은 분리한다. 부모 활동표의 기존 DVD·한글책·영어 그림책 칸을 유지하고 화면 및 PDF 요약에서도 DVD 시간을 별도로 표시하는 계획에 반영했다.
- 사용자 명시: DVD는 책과 별개의 목록으로 관리한다. DVD 전용 목록·관리 영역을 두고 기존 책 자료 유형에 DVD를 추가하지 않는 경계를 기록했다.
- 사용자 확정: 같은 날 같은 DVD의 반복 시청은 각각 별도 기록으로 저장하고 기간 시간에 합산한다. 60분씩 두 번 시청하면 2건·120분이며 건별 드롭다운의 최대 90분이 누적 합계를 제한하지 않는다.
- 사용자 확정: DVD 목록은 주가 바뀌어도 유지한다. 부모가 필요할 때 추가하거나 보는 중·안 보는 중 상태를 전환하며 다시 보는 중으로 돌릴 수 있다.
- 사용자 확정: 잘못 입력한 기록은 부모 활동표의 기존 삭제 기능으로 삭제한 뒤 다시 입력한다. 기록 한 건의 삭제는 공통 DVD 목록과 다른 기록에 영향을 주지 않도록 한다.
- 사용자 확정: DVD 등록에는 제목만 있으면 된다. 필요한 구분은 제목에 자유롭게 적는다.
- 제품 설계 합의를 마쳤다. 구현 기본안과 단계별 검증 작업을 작성했다. 앱 구현·마이그레이션 실행·배포는 아직 진행하지 않았다.
- 구현 최소안: DVD 전용 목록을 저장하고 시청 기록은 기존 DVD 수기 기록의 제목·시간을 활용한다. 추가 외래 키나 기존 기록의 강제 변환은 필수로 두지 않았다.
- 용어집에 공통 DVD 목록과 DVD 시청 기록을 추가했다.
- `npm run plan:workflow`로 사전 범위와 추천 검사를 확인했다. 기존 드래곤 계획 변경은 이번 작업에서 수정하지 않았다.
- 작성 문서는 수동 검토했다. 앱 코드·데이터베이스·운영 데이터는 변경하지 않았고 앱 테스트는 실행하지 않았다.
- 최종 계획 6개 파일의 UTF-8, task 링크 대상, 제목만 등록·공통 시간 선택지 및 합의 상태를 문서 검사로 확인했다. 통과했으며 앱 기능 검증과는 구분한다.
