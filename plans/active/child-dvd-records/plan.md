# 아동 DVD 시청 기록

## 상태

제품 설계 합의 완료. 구현·검증 작업을 정리했으며 앱 구현은 아직 시작하지 않았다.

## 목표

아동이 가족 공통 DVD 목록에서 본 DVD를 선택하고 시청 시간을 기록할 수 있게 한다. 기존 한글책·영어 그림책 읽기 기록을 유지한다.

## 확정된 요구

- DVD 목록은 아동별이 아닌 가족 공통이다.
- DVD는 책과 별개의 전용 목록으로 관리한다. 부모의 DVD 관리 영역에서 추가·제외하고 아동 DVD 탭은 이 목록에서 선택한다.
- 가지고 있거나 시청하는 DVD를 목록에 추가할 수 있다.
- DVD 등록 정보는 제목만 입력한다. 시즌·디스크 등의 구분이 필요하면 부모가 제목에 적는다.
- 안 보는 DVD를 선택 목록에서 뺄 수 있다.
- 시청 기록은 실제로 본 아동별로 남긴다.
- 기존 기록 팝업을 `읽기·DVD 기록`으로 바꾸고 `책 읽기 / DVD 시청` 탭을 둔다.
- 아동의 한글책·영어 그림책 읽기와 DVD 시청 모두 시간을 드롭다운으로 선택한다. 공통 선택지는 `30·40·50·60·70·80·90분`이며 기본 선택은 30분으로 해석한다.
- 책 읽기도 DVD와 동일한 시간 범위를 제공한다. 기존에 저장된 기록의 시간은 변경하지 않는다.
- 부모가 DVD를 `보는 중 / 안 보는 중`으로 전환하고, 아동에게는 보는 중인 DVD만 보여준다. 안 보는 DVD의 과거 기록은 보존한다.
- DVD 목록은 주가 바뀌어도 유지한다. 부모가 필요할 때 DVD를 추가하거나 보는 중·안 보는 중 상태를 바꾸며, 안 보던 DVD도 다시 보는 중으로 전환할 수 있다.
- DVD 시청 시간과 읽기 시간은 분리한다. 부모 활동표의 기존 DVD·한글책·영어 그림책 칸 구분을 유지한다.
- 같은 아동이 같은 날 같은 DVD를 여러 번 보면 매번 별도 기록으로 저장하고 일·주·월 시청 시간에 합산한다. 30~90분 제한은 한 번의 입력에 적용하며 누적 합계는 90분을 넘을 수 있다.
- 잘못 입력한 기록은 부모 활동표의 기존 수기 기록 삭제 기능으로 삭제한 뒤 다시 입력한다.

## 현재 구조 확인

- `app/child-reading-log-dialog.tsx`: 한글책·영어 그림책 구분, 제목 직접 입력, 시간 입력을 제공한다.
- `app/reading-manager-client.tsx`: 아동 팝업은 오늘 날짜로 읽기 기록을 저장한다. 부모 수기 입력에는 DVD 구분이 있으며 부모 활동표에도 DVD 칸이 있다.
- `lib/reading-types.ts`: `ManualLogType`에 `dvd`가 이미 있고, 수기 기록에 아동·날짜·제목·시간이 있다. 공통 DVD 목록은 없다.
- 기존 수기 DVD 기록은 목록 선택 없이 입력한 제목만 갖고 있다. 새 목록과 연결할 때 이 기록을 보존해야 한다.
- 현재 부모 화면의 ‘읽기 시간’은 DVD를 포함한 기간 내 모든 활동 시간을 합산한다. 사용자와 DVD 시간 분리에 합의했으며 요약과 PDF 표시에도 반영해야 한다.

## 화면과 동작

### 목록 관리

- 책 등록·조회 목록과 독립된 DVD 전용 목록 및 관리 영역을 제공한다. DVD를 기존 `Book`의 새 자료 유형으로 편입하지 않는다.
- 부모가 DVD 제목을 추가하고 `보는 중 / 안 보는 중` 상태를 관리한다. 이 상태 전환 방식과 과거 기록 보존은 사용자 동의로 채택했다.
- 가족 공통 목록은 같은 부모 계정의 아동들 사이에서 공유한다. 다른 가족의 목록과는 분리한다.
- 아동의 선택 목록에는 `보는 중`인 DVD만 표시한다.
- ‘안 보는 중’은 선택 목록에서 제외하는 상태로 취급하고, 과거 시청 기록은 보존한다. 다시 보는 중으로 돌릴 수 있다.
- 매주 별도 배정이나 초기화 없이, 현재 보는 목록을 다음 주에도 유지한다. 부모가 필요할 때 목록과 상태를 변경한다.
- 등록 폼은 제목만 입력한다. 상태는 별도의 보는 중·안 보는 중 전환으로 관리한다. 새 DVD는 보는 중으로 추가한다.

### 아동 기록창

- 기존 `읽은 책 기록` 진입을 `읽기·DVD 기록`으로 바꾸고 하나의 팝업 안에 `책 읽기 / DVD 시청` 탭을 둔다.
- 책 읽기는 현재 한글책·영어 그림책 구분과 제목 직접 입력을 유지하고, 기존 숫자 시간 입력을 공통 시간 드롭다운으로 바꾼다.
- DVD 시청은 공통 목록에서 DVD 하나와 공통 시간 드롭다운의 시간을 선택한다.
- 두 탭 모두 기본 30분, 10분 단위, 최대 90분으로 동일하게 제공한다. 선택지 정의와 검증 규칙을 함께 사용해 두 입력 화면이 달라지지 않도록 한다.
- 구현 기본안: 기존 책 기록처럼 오늘 날짜로 저장하고 부모 활동표의 해당 구분 칸에 반영한다.
- 구현 기본안: 선택할 DVD가 없으면 부모가 목록에 추가해야 함을 안내한다.
- 구현 기본안: 저장 실패 시 선택값과 팝업을 유지한다.
- 반복 시청은 기존 기록을 덮어쓰거나 합치지 않고 새 기록으로 추가한다. 예: 같은 DVD를 60분씩 두 번 기록하면 2건을 유지하고 하루 시청 시간은 120분이다.

### 부모 활동 기록과 시간 요약

- 기존 활동표의 DVD·한글책·영어 그림책 칸을 유지하고 아동 기록을 각각 해당 칸에 표시한다.
- 상단 요약과 PDF 요약에서 DVD 시청 시간을 읽기 시간과 별도로 표시한다.
- 읽기 시간에 DVD 시간을 중복 합산하지 않는다. 기존의 다른 활동 유형 집계는 이번 요청으로 재분류하지 않는 최소 변경안을 추천한다.
- 예: 한글책 30분·영어 그림책 40분·DVD 60분만 있으면 읽기 70분, DVD 시청 60분으로 표시한다.
- 부모가 예전에 직접 입력한 DVD 기록도 DVD 시간에 포함한다. 기존 기록의 시간 값을 새 드롭다운 범위에 맞춰 변경하지 않는다.
- 잘못 입력한 책 읽기·DVD 시청 기록은 부모 활동표에서 해당 수기 기록만 삭제한 뒤 다시 입력한다. DVD 시청 기록을 삭제해도 공통 DVD 목록이나 다른 시청 기록에는 영향을 주지 않는다.

## 구현 기본안

- 주요 제품 요구에 남은 질문은 없다. 아래 내용은 구현을 위한 최소안이며 별도 기능 추가 합의가 아니다.
- DVD 제목은 앞뒤 공백을 제거하고 빈 제목을 막는다. 예: `Arthur 시즌 1`, `Peppa Pig DVD 2`.
- 공통 DVD 목록은 책과 독립된 전용 테이블에 소유자·제목·활성 상태를 저장한다.
- 시청 기록은 기존 `manual_logs`의 `dvd` 구분에 선택한 DVD의 제목과 시청 시간을 저장하는 최소안을 우선 적용한다. 제목은 기록 시점의 값으로 보존하며 목록 상태 변경으로 과거 기록을 바꾸지 않는다.
- 현재 요구에는 DVD별 관계 조회가 없으므로 시청 기록에 DVD 외래 키를 추가하는 작업은 필수로 두지 않는다. 기존 제목만 있는 DVD 기록도 그대로 사용한다.
- 아동 시간 드롭다운 규칙을 부모 수기 입력 전체나 과거 데이터에 적용하는 전역 제약은 추가하지 않는다.

## 구현 시 지켜야 할 경계

- 공통 목록과 아동별 시청 기록을 구분한다.
- DVD와 책의 목록·관리 흐름을 분리한다. DVD는 책 배정 후보, 책 자료 검색, 읽은 책 권수에 포함하지 않는다.
- 현재 DVD 수기 기록 및 책 읽기 기록을 보존한다.
- 저장 구조는 위 최소안을 기준으로 구현 시 확정한다. 기존 `dvd` 기록 유형과 부모 활동표를 활용한다.
- Supabase 변경 시 `owner_user_id`와 RLS를 통해 가족별 데이터 경계를 유지한다. 목록과 기록 사이 연결도 같은 소유자에 한정한다.
- 데이터 계약을 바꾸면 타입·초기 데이터·저장 매핑·마이그레이션·관련 문서 및 검사도 함께 갱신한다.
- 드래곤·보상·일일 과제 달성 조건 변경은 요청 범위에 없다.

## 작업과 검증 계획

1. [설계 합의](tasks/01-design-contract.md) — 완료 → 검증: 이번 대화에서 제품 요구를 합의하고 구현 기본안과 구분했다.
2. [공통 DVD 목록과 부모 관리](tasks/02-dvd-catalog.md) → 검증: 독립 목록 추가·상태 전환, 과거 기록 보존, 가족 데이터 격리를 확인한다.
3. [아동 기록 팝업](tasks/03-child-record-dialog.md) → 검증: 두 탭의 공통 시간 선택, DVD 기록, 반복 시청, 빈 목록·저장 실패·모바일 동작을 확인한다.
4. [부모 보고서와 최종 검증](tasks/04-report-and-verification.md) → 검증: 화면·PDF 시간 분리, 삭제 후 재입력, 기존 흐름 회귀 및 `npm run verify`를 확인한다.

현재는 문서 작성 단계로 앱 검사·마이그레이션·운영 데이터 변경은 수행하지 않는다.

## Phase와 TDD step

기존 task는 범위와 수용 기준을 유지하고, 아래 phase는 구현 순서와 작은 TDD 작업 단위를 정의한다. 각 step을 순서대로 완료하고 관련 task의 전체 검증도 누락하지 않는다.

1. [Phase 1 — 가족 공통 DVD 목록](phase/01-dvd-catalog.md): 저장 경계와 부모 관리 화면을 만든다.
2. [Phase 2 — 아동 기록](phase/02-child-record.md): 공통 시간 규칙과 책·DVD 기록 흐름을 연결한다.
3. [Phase 3 — 보고서와 통합 검증](phase/03-report-verification.md): 시간 집계·화면·PDF를 맞추고 전체 흐름을 확인한다.

각 step은 요구 동작을 검증하는 실패 테스트를 먼저 확인하고, 필요한 최소 구현 후 해당 테스트를 통과시키고 정리한다. 테스트는 [테스트 작성 기준](../../../docs/testing-guidelines.md)의 정상·경계·잘못된 입력 검토와 Given–When–Then을 따른다. 실제 DB·브라우저·실기기 확인은 대역 테스트와 구분해 결과와 미실행 사유를 기록한다.
