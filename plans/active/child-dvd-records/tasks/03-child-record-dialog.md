# 아동 기록 팝업

상태: 구현 대기. 공통 DVD 목록 작업에 의존한다.

## 작업

- `읽기·DVD 기록` 팝업에 접근 가능한 책 읽기·DVD 시청 탭을 제공한다.
- 한글책·영어 그림책 구분과 제목 입력을 유지하고, 시간은 두 탭 모두 동일한 일곱 선택지와 기본 30분을 사용한다.
- DVD 탭은 보는 중인 DVD 하나와 시간을 선택한다. 선택한 제목으로 기존 `dvd` 수기 기록을 오늘 날짜·현재 아동에 저장한다.
- 매번 새 기록을 추가해 같은 DVD의 반복 시청을 보존한다. 저장 진행 중 중복 클릭은 막되 저장 완료 후의 별도 시청 기록은 허용한다.
- 빈 목록에서는 부모의 DVD 등록을 안내한다. 저장 실패 시 팝업과 입력값을 유지하고 오류를 표시한다.
- 기존 모달의 화면 내 표시, 포커스 복귀, 키보드 조작과 스크롤 복원을 유지한다.
- 화면 조율 파일에는 연결만 두고 탭·입력 UI와 공통 시간 정의 및 검증은 적절한 컴포넌트·모듈에 둔다.

## 검증

- 정상: 한글책·영어 그림책·DVD가 현재 아동과 오늘 날짜로 각각 저장된다.
- 경계: 기본 30분, 최소 30분, 최대 90분 및 모든 10분 단위 선택지를 두 탭에서 확인한다.
- 반복: 같은 날 같은 DVD를 60분씩 두 번 기록하면 2건·120분을 유지한다.
- 잘못된 입력: 빈 제목, DVD 미선택, 아동 입력의 허용 목록 밖 시간을 저장하지 않는다. 과거 기록이나 부모 수기 입력의 다른 시간 값은 제한하지 않는다.
- 저장 실패·로딩 실패·빈 목록, 닫기와 재열기, 탭과 키보드 조작을 검증한다.
- 기존 `child-reading-log-dialog.spec.mjs` 등 관련 브라우저 테스트를 갱신하고 모바일·데스크톱에서 입력과 저장 버튼에 접근할 수 있는지 확인한다.
