# 부모 보고서와 최종 검증

상태: 구현 대기. 목록 및 아동 입력 작업에 의존한다.

## 작업

- 기존 활동표의 DVD·한글책·영어 그림책 칸에 기록을 연결한다.
- 읽기 합계에서 DVD를 분리하고 DVD 시청 시간을 별도로 집계한다. 다른 활동의 기존 집계 규칙은 이번 요청으로 재분류하지 않는다.
- 화면 요약과 주간 PDF 요약에 같은 집계 규칙을 적용한다.
- 기존 부모 활동표의 기록 삭제와 수기 재입력을 활용한다. 삭제한 시청 기록만 합계에서 제외하고 공통 DVD 목록은 유지한다.

## 검증

- 정상: 한글책 30분·영어 그림책 40분·DVD 60분이면 읽기 70분·DVD 60분이다. 각 활동표 칸과 PDF에도 일관되게 반영된다.
- 경계: 기록 없음, DVD만 있는 기간, 읽기만 있는 기간, 반복 시청 누적 120분, 아동 전환 및 주·월 기간 전환을 확인한다.
- 호환: 공통 목록과 연결되지 않은 과거 DVD 수기 기록과 30~90분 범위 밖의 과거 시간도 원래 값으로 집계한다.
- 정정: 잘못 입력한 DVD 기록 한 건을 삭제하면 해당 시간만 빠지고 올바른 시간으로 다시 입력할 수 있다. 다른 기록과 목록은 유지된다.
- 단위·브라우저 테스트는 `docs/testing-guidelines.md`의 정상·경계·잘못된 입력과 Given–When–Then 기준을 따른다.
- 관련 저장소·계산·계약 검사와 `parent-report.spec.mjs`, `child-reading-log-dialog.spec.mjs` 및 관련 모바일·아동 완료 흐름을 검증한다.
- UI의 최소 검사 `npm run check:pwa`, `npm run typecheck`와 최종 `npm run verify`를 실행한다. `verify`에 브라우저 검사가 포함되지 않으므로 관련 브라우저 테스트는 별도로 실행한다.
- 실제 DB 마이그레이션·RLS, 모바일 브라우저, 실기기 PWA 검증 여부와 실행하지 못한 검사를 `review.md`에 구분해 기록한다.
