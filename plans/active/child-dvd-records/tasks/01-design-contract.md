# 설계 합의

상태: 제품 설계 합의 완료. 구현은 아직 시작하지 않았다.

## 확정

- DVD 선택 목록은 가족 공통이고 시청 기록은 아동별이다.
- DVD 목록과 관리 영역은 책과 독립된다. 책 등록·자료 검색·배정 후보와 읽은 책 권수에 DVD를 포함하지 않는다.
- 보유하거나 보는 DVD를 목록에 추가하고 안 보는 DVD를 선택 목록에서 뺄 수 있다.
- DVD 등록 정보는 제목만 입력한다. 필요한 시즌·디스크 구분은 제목에 적는다.
- 기존 팝업을 `읽기·DVD 기록`으로 바꾸고 `책 읽기 / DVD 시청` 두 탭을 제공한다.
- 한글책·영어 그림책 읽기와 DVD 시청에 동일하게 30·40·50·60·70·80·90분 드롭다운을 적용한다. 기본 선택은 30분으로 해석한다.
- 부모가 보는 중·안 보는 중 상태를 관리하고 아동에게는 보는 중인 DVD만 표시한다. 과거 시청 기록은 보존한다.
- DVD 목록은 주가 바뀌어도 유지한다. 부모가 필요할 때 추가하거나 상태를 바꾸고, 안 보는 DVD를 다시 보는 중으로 전환할 수 있다.
- 부모 활동표의 DVD·한글책·영어 그림책 칸을 유지하고, 화면·PDF 요약에서 DVD 시청 시간과 읽기 시간을 분리한다.
- 같은 날 같은 DVD의 반복 시청은 각각 새 기록으로 남기고 시간을 합산한다. 30~90분은 건별 입력 범위이며 누적 합계의 상한이 아니다.
- 잘못 입력한 기록은 부모 활동표에서 해당 수기 기록을 삭제한 뒤 다시 입력한다.

## 구현 기본안과의 구분

- 제품 요구에 남은 질문은 없다. 계획의 ‘구현 기본안’은 요구를 충족하는 최소 기술안이며 사용자에게 추가 기능을 약속하는 내용이 아니다.

## 합의 확인 사례

- 두 아동이 같은 DVD를 고를 수 있고 각자의 시청 시간은 따로 남는다.
- DVD를 등록해도 책 목록·책 배정 후보에 나타나지 않고 읽은 책 권수가 늘지 않는다.
- DVD를 안 보는 목록으로 옮겼을 때 새 선택과 과거 기록에 어떤 영향을 주는지 설명할 수 있다.
- 다음 주가 되어도 보는 중인 DVD가 선택 목록에 남는다. 안 보는 중인 DVD를 다시 보는 중으로 바꾸면 아동 선택 목록에 다시 표시된다.
- 책 읽기·DVD 시청 두 탭 모두 처음에 30분이 선택되고 동일한 일곱 시간 선택지를 제공한다.
- 두 탭 모두 각 허용 시간으로 저장할 수 있고 허용 범위 밖 시간은 저장하지 않는다. 기존 저장 기록의 시간은 바꾸지 않는다.
- 같은 아동이 같은 날 같은 DVD를 60분씩 두 번 기록하면 2건을 유지하고 하루·해당 주·해당 월의 DVD 시청 시간에 총 120분이 반영된다.
- 기존 책 기록과 목록 연결이 없는 과거 DVD 수기 기록이 보존된다.
- 잘못 저장한 DVD 시청 기록 한 건을 부모 활동표에서 삭제하면 그 기록만 없어지고 합계가 갱신된다. 공통 DVD 목록과 다른 시청 기록은 유지되며 올바른 시간으로 다시 기록할 수 있다.
- 한글책 30분·영어 그림책 40분·DVD 60분만 기록하면 화면·PDF 요약은 읽기 70분과 DVD 시청 60분으로 분리된다. 활동표는 기존의 각 구분 칸에 기록을 표시한다.
