# 공통 DVD 목록과 부모 관리

상태: 구현 대기.

## 작업

- 책 목록과 독립된 DVD 목록을 저장한다. 항목은 식별자·소유자·제목·활성 상태를 갖고, 부모 등록 폼에는 제목만 둔다.
- 전용 테이블의 마이그레이션·RLS와 저장·조회 매핑을 함께 작성한다. 타입과 초기 데이터 등 변경된 계약의 모든 사용처를 갱신한다.
- `owner_user_id`를 기준으로 같은 가족의 아동이 목록을 공유하고 다른 가족과는 격리한다.
- 부모 DVD 관리 영역에서 제목 추가와 보는 중·안 보는 중 전환을 제공한다. 보는 중으로 재전환할 수 있게 하고, 주간 초기화는 하지 않는다.
- DVD 목록 UI와 저장 로직은 응집된 컴포넌트·모듈로 분리한다. 기존 책 등록·검색·배정 흐름에 DVD를 편입하지 않는다.
- 아동 화면에서 보는 중인 공통 DVD를 불러올 수 있게 한다. 목록 로딩·실패·빈 목록을 구분한다.

## 검증

- 정상: 제목만으로 등록하면 보는 중인 목록에 나타나고 가족의 두 아동 모두 선택할 수 있다.
- 경계: 빈 목록, 한 항목, 주간 변경, 안 보는 중 전환과 재전환을 확인한다. 과거 시청 기록은 유지된다.
- 잘못된 입력: 빈 제목과 공백만 있는 제목을 막는다. 다른 소유자의 목록 조회·변경은 데이터베이스에서 차단한다.
- DVD 등록이 책 목록·배정 후보·읽은 책 권수에 영향을 주지 않는다.
- 저장소 단위 검증과 관련 계약 검사 후, 사용 가능한 환경에서 마이그레이션 및 RLS를 실제 데이터베이스로 검증한다. 대역 검사와 실제 DB 검증 결과를 구분한다.
