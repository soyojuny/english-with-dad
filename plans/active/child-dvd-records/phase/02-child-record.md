# Phase 2 — 아동 기록

상태: 구현 대기. 선행: [Phase 1](01-dvd-catalog.md). 범위와 수용 기준: [아동 기록 팝업](../tasks/03-child-record-dialog.md).

목표: 책과 DVD를 같은 팝업에서 기록하되 기존 책 기록과 과거 기록을 보존한다. 각 step은 실패 테스트 확인 → 최소 구현 → 통과 확인 및 정리 순서로 진행한다.

## Step 1. 아동 시간 규칙

- Red: 기본 30분과 30·40·50·60·70·80·90분의 허용, 30 미만·90 초과·10분 단위가 아닌 값의 거부를 검증한다.
- Green: 두 탭에서 공유할 선택지와 아동 입력 검증을 구현한다. 부모 수기 입력과 기존 기록에는 새 제한을 적용하지 않는다.
- 확인: 관련 단위 테스트를 실행한다.

## Step 2. 책 기록 탭

- Red: 팝업 이름과 책 탭, 한글책·영어 그림책 구분 및 제목 직접 입력, 기본값과 모든 시간 선택지, 빈 제목 거부를 검증한다.
- Green: 기존 책 입력을 공통 시간 드롭다운으로 바꾸고 오늘·현재 아동의 기존 저장 흐름을 유지한다.
- 확인: 관련 컴포넌트 및 기존 아동 기록 브라우저 테스트를 실행한다.

## Step 3. DVD 선택과 저장

- Red: 활성 DVD 선택 후 오늘·현재 아동에게 제목과 시간을 `dvd` 수기 기록으로 저장하고, 미선택을 거부하는 사례를 검증한다. 같은 DVD를 60분씩 두 번 저장하면 별도 2건이 남고, 저장 진행 중 중복 클릭은 한 번만 처리되는 사례를 구분한다.
- Green: DVD 탭을 연결하고 선택 당시 제목을 새 기록으로 저장한다. 기록과 목록은 독립적으로 유지한다.
- 확인: 저장소·컴포넌트 테스트를 실행하고 기존 부모 활동표의 DVD 칸 반영을 확인한다.

## Step 4. 실패와 접근성

- Red: 빈 목록 안내, 목록 로딩·실패 구분, 저장 실패 시 팝업과 선택값 유지 및 오류 표시를 검증한다. 닫기·재열기, 키보드 탭 조작, 포커스 복귀와 스크롤 복원 회귀를 확인한다.
- Green: 필요한 상태와 접근성 동작을 연결한다.
- 확인: `child-reading-log-dialog.spec.mjs` 등 관련 브라우저 테스트 및 모바일·데스크톱 화면을 확인하고 `npm run typecheck`를 실행한다.

완료 기준: 책과 DVD가 각각 저장되고 실패해도 입력을 잃지 않는다. 반복 기록의 일·주·월 합계는 Phase 3에서 별도로 검증한다.
