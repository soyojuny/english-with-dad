# Phase 3 검증 기록

## Step 1 — 읽기·DVD 시간 집계

- 기간별로 필터된 활동 기록에서 DVD와 나머지 시간을 분리 합산한다. 다른 활동과 과거 기록의 시간은 그대로 유지한다.
- `npm run test:unit`, `npm run typecheck`, `npm run check:contracts` 통과. 번들한 계산 함수를 직접 호출해 책 70분·DVD 60분, DVD 60분 두 건의 120분, 과거 DVD 15분과 120분의 135분을 확인했다.
- 기존 테스트는 새 함수를 직접 검증하지 않는다. 아동·주·월 전환 및 화면·PDF 연결은 아직 미검증이다. Chromium은 실행하지 않았다.

## Step 2 — 화면과 PDF

- 부모 화면과 주간 인쇄 요약에 동일한 읽기·DVD 분리 집계 함수를 연결하고 활동표의 기존 구분을 유지했다.
- 계약 검사, PWA 검사, typecheck, 기존 단위 테스트 20개 파일과 활동표 컴포넌트 검사 11건 통과.
- Firefox로 기존 부모 보고서 검사를 시도했으나 결과 없이 대기해 중단했다. 화면의 실제 렌더링과 PDF 출력 결과는 확인하지 못했다. 기존 인쇄 테스트의 통계 기대값은 새 DVD 합계를 반영하기 전 상태다. Chromium은 실행하지 않았다.

## Step 3 — 삭제와 재입력 경로 점검

- 코드 검토에서 삭제 요청은 소유자와 기록 ID로 제한되고 해당 기록만 상태에서 제거된다. DVD 재입력은 별도 저장 경로로 새 기록을 추가하며 목록과 분리된다. 기존 경로에서 수정이 필요한 결함은 발견하지 못했다.
- 기존 단위 테스트 20개 파일, `npm run check:contracts`, `npm run typecheck`, `npm run build` 통과. 기존 저장소 테스트는 삭제와 저장을 각각 검증한다.
- 삭제 후 다른 기록과 목록 유지 및 재입력까지 이어지는 화면 흐름과 실제 DB·RLS는 직접 검증하지 않았다. Chromium과 Firefox는 실행하지 않았다.
