# 01 — 위치 문제 재현과 회귀 기준

## Goal

현재 팝업이 문서 하단에 배치되는 현상을 브라우저 좌표로 확인하고, 수정 전 실패하는 회귀 테스트를 남긴다.

## Work

- 사용자의 계획대로 개발 진행 요청을 반영해 화면 중앙 표시 추천안을 구현 기준으로 채택한다.
- 기존 client HTTP fixture를 재사용해 긴 과제 목록을 가진 아동 화면을 준비한다. 운영 데이터는 사용하지 않는다.
- 페이지 상단과 스크롤된 상태에서 팝업을 열어 문서 높이, scrollY, 팝업 좌표, viewport 크기를 기록한다.
- 테스트의 자동 스크롤이 결함을 숨기지 않도록 팝업 내부 입력 조작 전에 위치를 검사한다.
- 정상 열기, 작은 viewport, 닫기·재열기, 빈 제목과 저장 실패의 기대 결과를 정리한다. 기존 저장 테스트는 재사용한다.

## Verify

- `npm run test:browser:client -- child-reading-log-dialog.spec.mjs`.
- 수정 전 화면 안 표시 assertion이 실패하는 것을 확인한다. fixture 오류와 요구사항 실패를 구별한다.
- 재현 결과와 원인 판단을 `../review.md`에 기록한다.

## Result

완료. 360·390·1280px 모두 수정 전 RED를 확인했다. 모바일 `scrollY` 5289px, 데스크톱 3291px 이동을 측정했으며, 좌표와 artifact는 [review.md](../review.md)에 기록했다.
