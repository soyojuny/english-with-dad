# 검토

정상: 불 아기의 기능 획득·승인 순서 공격·마지막 자세 유지.
경계: 성장 1/17/18일, 기능 미획득, 기회 0, 앉기·비행·화면 숨김·선택 변경, 움직임 줄이기.
잘못된 입력: 다른 가족/아동·지원하지 않는 속성/기능은 기존 RPC 경계에서 거절한다. 타입으로 불가능한 hook 입력을 만들지 않는다.

## 검증 결과

- 신규 불 공격 컴포넌트 테스트가 기존 구현에서 버튼 부재로 실패함을 확인한 뒤 구현했다.
- 서버 DB 테스트 56개 통과: 실제 migration 전체를 PGlite에 실행해 불·번개 동시 기능, 기회·성장 경계, 중복 요청, 다른 아동·소유자와 직접 수정 금지를 검증했다.
- 컴포넌트·hook 전체 214개 통과: 마지막 자세 유지, 자동 앉기 방지, 이동·날기·선택·숨김 전환, 움직임 줄이기와 기존 번개 동작.
- 앱 Chromium 회귀 4개 통과: 390/1280px의 불·번개 획득·프레임 재생·반대 방향 대기·다시 공격·날기 전환, 넘침 없음.
- 실제 Next/PWA 회귀 4개 통과: v25 worker 등록·새 시트 캐시·offline root/icon·등록 오류 안내.
- `npm run verify` 통과: contracts, SW, PWA, unit, typecheck, production build.
- PNG 3606×5194, 79칸, 마지막 5칸 미사용. 출력 해시·030~034 생략·029→035 겹침·정확한 043 종료 확인. 무손실 WebP의 보이는 RGB·전체 알파 변경 0.

후속 사용자 지시로 운영 `english-with-dad` 프로젝트에 `fire_tail_attack` (20261111091535)을 적용했다. 적용 전 함수 본문이 이전 정식 SQL과 일치하고 적용 후 새 SQL과 일치함을 확인했다. 드래곤 관련 4개 테이블의 RLS, anon 실행 금지, authenticated RPC 실행 허용 및 테이블 직접 수정 금지를 확인했다. 보안 advisor의 dragon_world 로그인 사용자 SECURITY DEFINER 실행 알림은 기존 의도된 RPC 구조이고, 다른 함수의 search_path/rls_auto_enable 및 유출 비밀번호 보호 권고는 이번 변경 밖이므로 수정하지 않았다. 검증된 변경은 요청에 따라 main 커밋·origin/main 푸시로 게시한다. 원본의 발끝 잘림·희미한 연기 손실·불꽃 테두리·짧은 겹침 윤곽과 약 71.4MiB 픽셀 메모리는 에셋 문서에 기록했다. 데이터 형식은 기존 DragonSkill을 그대로 사용하므로 reading-types/data 및 RPC mapper 변경은 필요하지 않다.
