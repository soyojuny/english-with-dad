# 불 아기 꼬리 공격 앱 연결

사용자가 승인한 영상 캡처 샘플을 앱에 적용한다. 001은 시작 자세이며 004~029→035~043을 사용한다. 002~003의 대기와 030~034의 정면 서기를 제외한다. 029→035와 후반의 짧은 겹침·감속을 유지하고 마지막 043의 반대 방향 자세로 대기한다. 기존 서기 원화로 교체하거나 방향을 즉시 되돌리지 않는다.

1. 승인 미리보기의 타임라인을 정식 투명 시트로 담고 출처·배치를 기록한다. → 검증: 칸 크기·프레임 순서·마지막 자세·PNG/WebP 픽셀 확인.
2. 번개와 같은 보상 기회 1개로 불 아기에게 꼬리 공격을 허용한다. 기존 기능·가족 소유권·RLS를 유지한다. → 검증: migration을 실행하는 DB 테스트의 재시도·기회·성장·다른 소유자 경계.
3. 공격 중 이동·날기를 막고, 끝나면 마지막 자세를 유지한다. 이동·날기·선택 변경은 대기 자세를 해제한다. 번개 동작은 유지한다. → 검증: hook/component와 모바일·데스크톱 브라우저 테스트, 움직임 줄이기, npm run verify.

현재 자세·방향은 장면의 일시 상태이며 DB에 저장하지 않는다. 앱 코드·정식 에셋·migration 준비가 범위이고 운영 DB 반영·Git 게시·배포는 별도다. 사용자의 샘플 승인과 앱 적용 지시로 작업 계약을 확정했다.
