# 무속성 아기 드래곤 날기

사용자가 승인한 새 이륙(13~42, 25·26 교체본), 기존 이동(36~47), 대기(58~66)를 사용한다. 착륙은 이륙 역순이다. 기존 그림의 크기·형태를 재생성하지 않고 검정 배경을 투명 분리한다.

1. 3일 보상 기회 1개로 선택한 무속성 아기에게 날기를 저장한다. 중복 요청은 추가 차감하지 않는다. -> 검증: 실제 migration을 실행하는 DB 테스트로 기회 경계·다른 가족·잘못된 입력·재시도를 확인한다.
2. 획득 후 날기 버튼으로 이륙, 기존 스틱으로 좌우 비행, 손을 떼면 공중 대기, 다시 누르면 역순 착륙한다. 이착륙 중 이동은 막고, 비행 중에는 앉지 않는다. -> 검증: 컴포넌트 시간·포인터 테스트와 모바일/데스크톱 브라우저 테스트.
3. 정식 PNG/WebP·빌드·PWA 캐시와 문서를 갱신한다. -> 검증: 투명도·이미지 로드·움직임 줄이기와 npm run verify.

보상 기회는 기존 아동 공용 누적을 사용하고 기능은 드래곤별 소유다. 이번 동작의 사용/최초 획득 범위는 무속성 아기(1~17일)다. 이후 성장·속성 선택에도 획득 기록은 남지만 이번 이미지가 적용되는 범위를 벗어나면 버튼을 표시하지 않는다. 비행 위치와 현재 동작은 저장하지 않는다. 새로고침·다른 드래곤·꾸미기 진입 시 지상 대기로 돌아간다. 앱 배포·원격 DB 적용·커밋은 이번 로컬 구현과 별개다.

후속 사용자 요청으로 운영 DB 적용·커밋·배포까지 승인되었다. 2026-11-08 운영 `english-with-dad` 프로젝트에 `dragon_flight` 마이그레이션을 적용했다. 앱은 기존 main→Vercel Production 연동으로 배포한다.
