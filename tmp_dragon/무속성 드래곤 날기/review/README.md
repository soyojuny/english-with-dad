# 무속성 드래곤 날기 이미지 검토

`preview.html`을 브라우저에서 열면 원본 구간과 선별 후보를 바꿔 재생할 수 있습니다. 일시정지, 한 장씩 보기, 재생 속도 변경, 프레임 탐색을 지원합니다. 이미지는 HTML에 포함되어 있어 서버 없이 열 수 있습니다.

## 원본 확인

- PNG 83장, 각 498×425 픽셀, 전체 12,098,456바이트(약 12.1MB).
- RGB 이미지이며 투명도가 없습니다. 검정 배경은 실제 이미지 픽셀입니다.
- 정지 이미지에는 원본 영상의 FPS 정보가 없어 재생 속도는 확정할 수 없습니다. 미리보기의 12fps는 비교용 가정입니다.

## 선별 후보

| 용도 | 원본 번호 | 장수 | 비교용 속도 |
| --- | --- | ---: | ---: |
| 이륙 | 001~029 중 홀수 번호 | 15 | 6fps |
| 오른쪽 이동 비행 | 036~047 | 12 | 12fps |
| 공중 대기 | 058~066 | 9 | 12fps |

총 36장입니다. 이륙은 원본 12fps를 가정할 때 두 장마다 선택하여 같은 길이로 비교합니다. 031~035는 이동 비행 자세로 바뀌는 전환 구간이고, 051~057도 대기 자세로 돌아오는 전환이 남아 있습니다. 이 구간은 반복 주기에서는 제외했지만 실제 동작 전환에 필요한지는 적용 시 따로 확인해야 합니다.

위 번호는 정적 프레임 검토로 선정한 반복 후보입니다. 반복 경계에서 몸통, 날개, 꼬리가 튀지 않는지 재생하며 확인한 뒤 확정해야 합니다. 미리보기의 이륙 반복은 비교 편의를 위한 것이며 실제 게임에서는 한 번 재생합니다.

## 용량 비교

같은 해상도를 유지하고 WebP 품질 85로 시험 인코딩한 이미지 데이터의 합계입니다. 검정 배경을 유지한 수치이며 투명화 후 용량은 달라집니다.

- 원본 전체 83장 PNG: 약 12.1MB.
- 전체 83장 WebP: 1,098,814바이트(약 1.10MB).
- 선별 36장 WebP: 474,644바이트(약 475KB).

프레임을 줄이기 전에도 포맷 변경만으로 용량이 크게 줄어듭니다. 이륙 6fps가 거칠게 느껴진다면 이륙 30장을 유지하는 선택도 가능합니다. 위 수치는 이미지 데이터만의 합계이며, 모든 비교 프레임을 Base64로 포함한 preview.html의 파일 크기와는 다릅니다. 화질은 최종 표시 크기에서 원본과 비교해야 합니다.

## 적용 전 확인할 문제

1. **날개 잘림:** 008, 009, 010, 019, 020, 029, 030에서 밝기 40 초과 픽셀이 좌우 이미지 경계에 닿습니다. 전체 비교표에서 오른쪽 날개 잘림이 보입니다. 선별 이륙에도 009, 019, 029가 포함되어 있으므로 이륙 후보는 그대로 최종 자산으로 확정하기 어렵습니다. 단순 여백 추가나 크기 축소로 이미 잘린 날개가 복구되지는 않습니다.
2. **배경 투명화:** 게임 배경에 올리려면 검정 배경 제거가 필요합니다. 드래곤 자체도 어두우므로 단순히 어두운 픽셀 전체를 지우면 몸과 외곽선이 손상될 수 있습니다. 이번 검토에서는 투명화를 하지 않았습니다.
3. **이륙 높이:** 자세 변화에 비해 화면 안에서 몸통이 위로 이동하는 양은 뚜렷하지 않습니다. 게임에서는 캐릭터의 화면상 높이를 올리는 연출을 함께 검토해야 합니다. 현재 프레임별 위치를 임의로 보정하지 않았습니다.
4. **반복 연결과 기준점:** 날개를 포함한 외곽 크기가 프레임마다 바뀝니다. 각 프레임을 서로 다른 크기로 밀착 잘라 사용하면 캐릭터가 흔들릴 수 있으므로 공통 캔버스와 몸통 기준점을 유지하는 편이 좋습니다.
5. **착지:** 별도 착지 동작은 확인되지 않습니다. 이륙 영상을 역재생하는 것만으로 자연스러운 착지가 보장되지는 않습니다.

## 생성한 검토 자료와 확인 범위

- `preview.html`: 원본/선별 구간 비교용 재생 화면. 원본 캐릭터의 형상과 위치는 변경하지 않았고, 검토 표시용 WebP 인코딩만 했습니다.
- `contact-1.jpg`, `contact-31.jpg`, `contact-61.jpg`: 번호를 표시한 전체 프레임 비교표.
- `review-data.json`: 파일 용량, 선별 번호, 이미지 경계 접촉 번호.
- Chromium으로 이미지 디코딩, 일시정지, 한 장씩 보기, 원본/선별 전환, 모바일 가로 넘침 없음, 스크립트 오류 없음을 확인했습니다. 이는 반복 동작의 자연스러움에 대한 최종 시각 검수를 대신하지 않습니다.

원본 PNG와 앱 코드는 변경하지 않았습니다.
